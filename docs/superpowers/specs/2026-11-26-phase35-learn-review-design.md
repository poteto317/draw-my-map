- feature-spec 第2周対応（範囲・知見）: L-061 inventory 節・L-001 成否表・知見適用表（L-203 含む）・`learn` 引き継ぎを tour 同型に拡張・cards 100/50 の意図・§9 実装順

## 決めたこと

1. **スコープ**: 088 と 089 を **1 PR** で実装する（ユーザー選択 1B）。
2. **穴埋めで隠す対象**: **ラベルのみ**。メモ・イラスト・カスタム属性・タスク表示はそのまま。クリックまたは Enter で、フォーカス／選択中のそのノードのラベルだけ開示する。
3. **入口**: コマンドパレットとツールバーのトグル（日本語）。プレゼン再生（Phase 31）とは **別モード**。同時に両方は開始しない（一方が稼働中なら他方の開始を拒否）。
4. **進捗の永続化**: 「開示済みノード ID」をマップ文書の任意フィールドとして保存する（ユーザー選択 4B）。リロード後も同じ開示状態を復元する。学習モード終了だけでは開示済みは消さない（明示の「進捗をリセット」で消す）。
5. **編集との関係**: 学習モード中は構造編集・ラベル編集・取込・AI 適用・統合などを無効（表示・開示・カード操作・終了・進捗リセットのみ可）。終了で通常編集に戻る。保護モードでは学習の開始・開示・カード閲覧は可、進捗リセットとカード編集は不可。
6. **復習カード**: 親子関係とメモから問題を **ローカル生成**（外部 AI API は使わない）。生成結果は文書に保存し、学習モード内のカード UI でめくれる。

## 1. 目的

マップの構造を思い出す練習（穴埋め）と、親子・メモから作った短い問題で復習できるようにする。共有サーバーや間隔反復アルゴリズムの高度化は対象外。

## 2. 非目標

- AI による問題生成（Phase 32/33 の API）
- Anki 等へのエクスポート、間隔反復スケジューラ
- 音声読み上げ・タイマー試験モード
- プレゼンツアーとの統合再生
- スマートフォン専用 UI（Phase 36）

## 3. データモデル

### 3.1 学習状態（文書級）

`NodeMapState` に任意項目 `learn?: MapLearnState` を足す（`version: 3` のまま。L-825）。

```ts
type MapLearnState = {
  version: 1;
  /** ラベル開示済みのノード ID。欠落・空配列は「未開示」。存在する ID のみ有効 */
  revealedNodeIds: readonly number[];
  /** 復習カード。0 件ならフィールド欠落または cards 空を正規化で欠落扱い */
  cards?: readonly MapReviewCard[];
};

type MapReviewCard = {
  id: string; // 文書内で一意（新規採番。ノード id と混同しない）
  prompt: string; // 正規化後 1〜500 文字
  answer: string; // 正規化後 1〜500 文字
  /** 生成元の参照（表示用。ノード削除後は dangling 可） */
  sourceNodeIds: readonly number[]; // 1〜3 件。正規化後に重複除去
};
```

### 3.2 正規化・互換

- デコード時: `learn` がオブジェクトでない・`version !== 1` → **`learn` ごと削除**（マップは開く）。
- `revealedNodeIds`: 数値でない・非整数・負・重複 → 除外。文書に存在しない ID は **残してよい**（後でノードが戻る場合に備え。表示時は存在するノードだけ開示扱い）。
- `cards`: 要素不正は除外。`prompt`/`answer` 不正はカードごと除外。残 0 件なら `cards` キーを出さない。最大 **100** 件（超過は先頭から切り捨て、切り捨て後 0 なら `cards` 欠落）。
- `null` の `learn` は欠落と同等（Phase 34 の任意フィールド方針）。

| 操作 | `learn` |
|------|---------|
| 同一マップの自動保存・明示保存・ライブラリバックアップ export / 同一 ID への復元 | **含める** |
| JSON 書き出し（マップ本文）・JSON 全文取込（置換） | **含める**（取込後はデコード正規化） |
| 別名保存（新 ID）・新規マップ作成・テンプレートからの新規 | **含めない** |
| 枝の切り出しで別マップ新規 | **含めない** |

`cards` の正規化上限 **100** 件は、外部 JSON・将来の手編集を想定した防御上限。本 Phase の生成は **50** 件までであり、UI から 51 件以上を作る経路は持たない。

### 3.3 Undo

- 開示（1 ノード追加）・進捗リセット・復習カード生成（既存 `cards` の全置換）は **各 1 Undo**（文書変更）。本 Phase にカード単体の削除・並べ替え UI は無い。
- 学習モードの **開始・終了**、カードのめくり（表裏）は Undo に載せない（閲覧操作）。

## 4. 学習モード（088）

### 4.1 開始・終了

- トグル／コマンド「学習を開始」「学習を終了」。
- 開始時: プレゼン再生中なら拒否（日本語理由）。逆も同様。
- セッション UI 状態 `learningActive: boolean` は **永続化しない**（文書の `learn` とは別）。アプリ再読込後は通常モードで開き、開示済みは `learn.revealedNodeIds` から描画に反映できるが、編集ロックは学習モード中のみ。

### 4.2 表示

- **学習モード中のみ**、マップ（Pixi）とアウトラインのラベル文字列を穴埋めする: ノード ID が `revealedNodeIds` に無いときプレースホルダ（例: `？？？`）。学習モード外では常に実ラベルを表示する（保存済みの `revealedNodeIds` は再開時の開示状態の復元にだけ使う）。矩形サイズは **実ラベル幅を維持**（レイアウトジャンプを避ける。プレースホルダは視覚のみ）。
- 開示後は通常ラベル。再隠す個別操作は持たない（まとめてリセットのみ）。
- 学習モード中で未開示でも、選択・パン・ズーム・折りたたみ・フォーカスは可（構造変更は不可）。

### 4.3 開示操作

- 対象: 現在の主選択がちょうど 1 件のノード。
- 操作: ノードクリック（既に選択済みなら再クリックでも可）または Enter。未開示なら `revealedNodeIds` に追加して 1 Undo。既開示・非選択・複数選択は no-op（履歴なし）。
- 進捗リセット: 確認ダイアログ後に `revealedNodeIds` を空にし 1 Undo。保護モードでは不可。

## 5. 復習カード（089）

### 5.1 生成規則（決定的）

コマンド「復習カードを生成」は **学習モード中のみ**実行可（`learn-generate-cards`）。現在の `nodes` から次を **最大 50 件**まで作る（既存 `cards` は置き換え。1 Undo）。

優先順（どちらも条件を満たすノードは両方の型を出しうるが、同一 `sourceNodeIds` 集合の重複カードは作らない）:

1. **親子**: 親があり、親ラベルと子ラベルがともに非空。  
   - prompt: `「{親ラベル}」の下にある項目は？`  
   - answer: 子ラベル  
   - sourceNodeIds: `[親id, 子id]`  
   - 正規化後の `prompt` または `answer` が 501 文字以上になる候補は **スキップ**（切り詰めしない）
2. **メモ**: `node.note` が非空（正規化後）。  
   - prompt: `「{ラベル}」のメモの要点は？`（ラベル空なら `このノードのメモの要点は？`）  
   - answer: メモ全文（500 超は末尾を切らず **拒否してスキップ**。メモが 500 超のノードはカード化しない）  
   - sourceNodeIds: `[nodeId]`  
   - 正規化後の `prompt` が 501 文字以上になる候補も **スキップ**

生成順: `indexNodeForest` の `roots` 配列順と `childrenByParent` の配列順による深さ優先（`traverseNodeForest` と同じ子の並び。pre-order 相当）でノードを列挙し、1 周目に親子カード、2 周目に同じ列挙順でメモカード。上限 50 で打ち切り。

再生成は常に全置換。手編集 UI（文言の微修正）は本 Phase では持たない（削除と再生成のみ）。

### 5.2 カード UI

- 学習モード中のみ「復習カード」パネル／ダイアログを開ける。
- 表: prompt、裏: answer。スペースまたはボタンで裏表。左右で前後カード。
- カード 0 件なら「生成」を促す空状態。
- ノード削除で dangling になってもカードは残す（answer は保存文字列のまま）。

## 6. 編集可否・競合

| 状態 | 学習開始 | 開示・カードめくり | 進捗リセット・カード生成 | 構造編集 |
|------|----------|-------------------|-------------------------|----------|
| 通常 | 可 | — | 不可（学習開始後） | 可 |
| 学習中 | 終了のみ | 可 | 可（非保護） | 不可 |
| プレゼン中 | 不可 | — | — | 既存どおり不可 |
| 保護 | 可 | 可 | 不可 | 不可 |

競合検出・履歴比較は `learn` を構造比較に含める（`areMapStatesEqual` / `isDocumentContentEqual` に `learn` を追加。`MapTour` の `tour` と同型）。`revealedNodeIds` は数値昇順にソートしてから比較する。`cards` は **配列の保存順**（`tour.steps` と同様に添字ごとに `id`・`prompt`・`answer`・`sourceNodeIds`（各 ID 昇順）を比較）で等価判定する。

### 7.2 L-001（操作の成否）

文書を変える操作は outcome 型で呼び出し元へ返す（成功時だけ通知・後続・履歴を進める）。

| 操作 | 成功 | 失敗・no-op（例） |
|------|------|-------------------|
| 開示 | `revealedNodeIds` に追加・1 Undo | 未選択・複数選択・既開示・学習モード外 |
| 進捗リセット | 確認後に空・1 Undo | キャンセル・保護モード・学習モード外 |
| カード生成 | 新 `cards` 全置換・1 Undo | 学習モード外・保護モード・生成 0 件（文書は変えない） |
| 学習開始 | `learningActive` 真 | プレゼン再生中・（将来拡張の拒否条件） |
| 学習終了 | `learningActive` 偽 | 既に終了 |

拒否・no-op 時は `operationNotices` に日本語理由を出す（L-166）。成功表示は `ok: true` のときだけ。

## 10. 検証の観点

- 学習モード中、未開示ラベルが Pixi とアウトラインでプレースホルダになり、実ラベル幅で矩形が保たれる。学習モード外は実ラベル。
- 開示が Undo 1 回で戻り、保存・再読込後も `revealedNodeIds` が復元される。
- 学習中は構造編集コマンドが無効。プレゼンと相互排他。
- カード生成が決定的で上限 50。メモ 501 文字はスキップ。
- 別名保存で `learn` がコピーされない。
