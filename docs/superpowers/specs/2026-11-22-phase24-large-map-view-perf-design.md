## 決めたこと

1. **範囲**: 041・042・043・044・045 をこの機能で実装する（ユーザー選択 1A）。
2. **深さ制限（041）**: ルートからの深さ N まで。ヘッダーで無制限／1／2／3…。解像度・折りたたみ・枝集中と積集合。
3. **一時強調（042）**: 「オフ／検索ヒット／選択枝」。非対象は半透明。非表示にしない。UI はヘッダー（コマンドパレットは任意）。
4. **位置の目印（043）**: マップごと永続ピン。一覧ジャンプ。キャンバスに印。
5. **ミニマップ（044）**: 2D canvas サムネ＋ビューポート矩形。パンのみ。
6. **大規模対応（045）**: ビューポート AABB カリング。
7. **実装順（1 プラン・タスク群）**: ①深さ可視 → ②強調 alpha → ③ピン永続/UI → ④カリング → ⑤ミニマップ → ⑥仕様/ROADMAP。ミニマップはカリング後でも**全ノードを間引き描画**（最大描画点数の上限を設け、超過時は間引き）して大規模時も応答を保つ。

- ミニマップ上での編集・ズーム。

## 要件

### 041 深さによる表示制限

- 深さ 0 = ルート。`depth <= N`（無制限は制限なし）。
- UI: 解像度フィルタ付近。
- 保存: **セッション内のみ**。ブックマーク非含有。
- 検索着地: `d > N` なら N を `d` へ一時引き上げ。
- 辺: **両端とも論理可視の辺のみ**。

### 042 一時的な強調表示

- 検索モード: ヒット ∩ 論理可視のみ強調。
- 選択枝モード: 選択各 ID の部分木の和。選択 0 件 → 強調集合空 → 全ノード通常 alpha。
- 非強調の論理可視: `contentAlpha`（例 0.25）。ヒットテスト維持。
- UI: ヘッダー必須。

### 043 位置の目印

- キー: `draw-my-map.node-pins.v1`。マップ ID → `{ nodeId, createdAt }[]`。上限 50/マップ。
- 登録: 選択ちょうど 1 件。削除: 一覧から。
- ジャンプ: 既存フォーカス + reveal（必要なら深さ引き上げ）。成否を Result で返す（失敗時はフォーカス副作用を続けない）。
- キャンバス: ピン印。
- **欠落**: マップ nodes 読込／ピン読取のたびに、存在しない `nodeId` を**一覧から除去**し `repaired` を返し得る。欠落行は残さない。

#### ピンストレージ契約（L-001 / L-002 / L-461 / L-921）

- `readPins(mapId)`: `ok` | `corrupt` | `read-error`。失敗を空成功にしない。
- `writePins(mapId, pins)`: `ok` | `quota-exceeded` | `write-error`。成功時のみ UI 一覧を確定更新。
- 空フォールバックは**毎回新規配列**。キー未存在と「ユーザーが全削除した空」は ok+空でよいが、corrupt/read-error と混同しない。
- 更新は**最新読取 → エントリ追加/削除 → 書き戻し**。無関係操作でストア全体を盲書きしない。
- 経路: ピン UI、マップ切替時の読取、ノード削除後の掃除。ライブラリ一括バックアップへの含有は非目標（現状どおり）。

### 044 ミニマップ

- サイズ固定。描画: layout 全ノード（論理不可視は薄色）。点数上限超過時は間引き。
- ビューポート矩形。クリック／ドラッグでパン。ズームなし。

### 045 大規模マップ対応

- ノード: マージン付きビューポート矩形 ∩ layout AABB。
- 辺: 両端がカリング後集合に含まれるもののみ。
- パン／ズームで集合更新。

## 失敗・空状態

- ピン read/write 失敗・quota: notice。一覧は成功結果のみ反映。
- ミニマップ: ノード 0 件は空。
- 深さで表示 0 件: 無制限へ戻す導線。

## テスト方針（TDD）と L-060 配線

ドメイン:

- 深さ積集合、強調集合、ピン codec（上限・除去 repaired）、カリング AABB。

配線（必須・省略可 props は使わない／使うなら変異で落とす）:

1. 深さ変更 → `visibleNodeIds` が変わる（MapEditor または displayState 結合）。
2. 強調モード → 非対象の alpha 経路（render または MapStage props）。
3. ピン登録が単一選択のときだけ成功。
4. ピンジャンプ失敗時にフォーカスが走らない。
5. ミニマップのビューポート矩形が viewport 変更に追従。
6. カリング関数に画面外ノードが入らない。
