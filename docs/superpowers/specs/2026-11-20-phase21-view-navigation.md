# Phase 21 集中表示と閲覧状態の保存の設計

対象は ITEM-026 と ROADMAP の候補018・019・027〜030。

## 操作と表示

- 「枝に集中」で主選択ノードとその子孫だけをキャンバスに表示する。「集中表示を終了」でマップ全体の表示範囲に戻る。終了時は位置と倍率を維持し、閲覧履歴から終了を取り消した場合は終了直前の集中先と表示状態を復元する。他の枝の折りたたみ設定、ノードの親子関係、座標は保持する。集中先のノードを削除した場合は集中状態を解除する。集中表示中に枝の外へ検索、パンくず、同一マップ内のリンクなどから移動した場合も集中状態を解除する。
- ノードの可視範囲は従来の折りたたみと解像度フィルターに集中範囲を重ねて求める。集中先自身は解像度レベルにかかわらず表示する。集中先の祖先の折りたたみが復元時に残っている場合、その祖先を展開してから適用する。自動配置は従来の折りたたみ投影を使い、投影に渡す森林の親参照は維持する。
- 「全体に合わせる」は集中表示中に「表示中の枝に合わせる」と表示し、対象範囲内の折りたたみで隠れていないノードの外接矩形を使用する。解像度で隠れているノードも境界の計算に含めるため、自動レベルの変化後も対象が画面内に収まる。「選択に合わせる」は表示中の選択ノードすべての外接矩形を使用する。画面内の余白を設け、既存の倍率範囲でクランプする。倍率下限でも大きすぎる図は中央に配置する。空マップや未計測のキャンバスでは操作を無効にするか何も変えない。
- 「枝を一括展開」「枝を一括折りたたみ」は主選択の枝の内部ノード全体（枝の根を含む）の閉状態を一度に更新する。枝の外側は保持する。葉と操作後に変化しない対象は操作を無効にする。一括折りたたみ後に枝の根だけ開けば、内部ノードの閉状態を確認できる。
- パンくずは実際のルートから主選択ノードまで順に表示する。現在のノードには aria-current を付け、祖先を選ぶと検索と同じ表示・選択・中央移動を使う。空ラベルは既存表示と同じ規則で付ける。現在位置や戻る・進むの操作はキャンバス表示に置き、アウトラインの編集操作は維持する。

## 閲覧履歴とブックマーク

- 閲覧する状態は現在のビューポート変換、主選択・複数選択の ID、集中先 ID、折りたたみ ID 群、解像度モードで表す。自動解像度を正確に復元するため、フィルターの自動レベルも保持する。固定解像度モードでは現在の固定レベルの代わりに previousAutoLevel を保存する。適用時はスナップショットの倍率と自動レベルを一緒に反映し、旧倍率による一時的な描画で自動レベルのヒステリシスを更新しない。
- マップ内検索、同一マップ内に着地する横断検索・マップ間リンク・被リンクからの移動、パンくず、枝集中と解除、範囲に合わせる、ブックマーク適用、選択ノードへの既存の中央移動を閲覧の区切りにする。実行直前の表示状態を記録し、「閲覧を戻る」では現在の状態を進む側に置いて直前へ戻る。「閲覧を進む」も対称。新規移動は進む側を破棄する。無効な操作や表示に変化がない操作、パンやホイールの各イベントは履歴項目を作らない。履歴は最大50件とし、マップ切り替えやマップ本文の置き換え（resetRevision）で破棄する。別マップへのジャンプは既存のマップ切り替えを使い、そのマップの閲覧開始位置とする。アウトラインからキャンバスへ移るとき、移動先が集中範囲外なら集中状態を解除する。編集 Undo/Redo のスタックには積まない。同一マップの編集 Undo/Redo では閲覧履歴を維持し、履歴適用時に現在の森林へ正規化する。旧 documentRevision に属する保留要求は破棄する。
- ブックマークは現在の表示状態を名前付きで保存し、適用と削除ができる。前後空白を除いた非空の一意な名前を使用する。マップ ID と作成日時で識別する専用ローカルストレージを使い、再読み込みと同じマップの再訪に対応する。再訪時には一覧だけを読み込み、明示的に選んだブックマークだけを適用する。既存のマップ本文、自動保存、バックアップ形式は維持する。保存できないモードでは現在の閲覧操作を使えるままにし、ブックマーク保存ができないことを伝える。
- 復元時に消滅した選択・集中先 ID は解除し、閉 ID は現在も子を持つものに絞る。現在の可視条件外の選択は除き、主選択が除かれた場合は既存の選択補正規則を使う。壊れた値、読み込み失敗、書き込み失敗で既存の保存値を置き換えない。書き込み前に最新版を読み、成功後に一覧を更新する。同じウィンドウでマップを切り替えたとき、前のマップの状態を使い回さない。

- ブックマークはマップのライブラリエントリに属する。同じエントリの JSON 取り込みや外部変更の再読み込みでは、名前と保存設定を保持し、参照先は置き換え後の同じ ID を指す。新規マップ、別名保存、ライブラリバックアップからの新規追加には引き継がない。ゴミ箱への移動中は保持し、元 ID に復元すれば再び使える。衝突により新しい ID で復元した場合はブックマークのキーを移し、既存マップのキーは変更しない。
- 個別の完全削除、ゴミ箱を空にする操作、期限切れによる削除では、対応するゴミ箱項目の削除が確定した後にブックマークを削除する。ブックマーク領域の操作だけが失敗してもマップ本文の成功を巻き戻さず、表示可能な経路では既存の補助データの失敗通知規則に従う。作成日時を含むキーにより、旧エントリの残留データが後から同じ ID に割り当てられたマップに表示されることを防ぐ。

## 責務

- 森林・祖先・一括開閉は既存の NodeCollapseIndex、表示は useMapDisplayState、検索と移動は useNodeSearchNavigation を活用する。
- MapEditor が集中・閲覧履歴・復元を組み立てる。MapStage がキャンバスサイズ、位置の計算、実際のビューポート更新とジェスチャー中断を扱う。検索、履歴復元、フィットの保留要求は文書世代と要求 ID で判定する。同一世代でも新しい適用・移動要求が発行された後に前の要求を適用せず、古い要求の応答で新しい位置や履歴を更新しない。
- 既存のノード編集コマンドは正規の森林を使い、画面の可視集合は従来の可視条件として渡す。書き出しと保存には表示投影を渡さない。
