# Phase 3 子孫ノード一括移動設計

## 目的

ドラッグしたノードに子孫がある場合、対象ノードを根とする部分木全体を同じ差分だけ移動し、相対配置を維持する。

この機能はビューポート操作とは異なるツリードメインの責務として、Phase 3の3番目のPRで実装する。

## 要件

- ルートノードを移動すると、その子孫すべてを同じ`dx`と`dy`だけ移動する。
- 中間ノードを移動すると、そのノードを根とする部分木だけを移動する。
- 葉ノードは従来どおり単体で移動する。
- 親子の相対配置、`parentId`、ノードサイズ、ラベルを変更しない。
- 無関係なノードの値とオブジェクト参照を維持する。
- ノード配列と各入力ノードを変更しない。
- 対象ノードが存在しない場合は何も変更しない。
- 不正な循環を含むデータでも無限ループしない。
- `useNodes.moveNode(id, x, y)`の公開APIを維持する。

## ドメイン境界

部分木の探索と座標更新は`client/src/domain/nodes/nodeTree.ts`へ置く。Pixi gesture、Reactコンポーネント、Hookへ子孫探索を重複させない。

```ts
export function moveNodeSubtree(
  nodes: readonly Node[],
  rootId: number,
  x: number,
  y: number,
): Node[] | null;
```

戻り値の契約は次のとおりとする。

- `rootId`が存在しなければ`null`を返す。
- 有効な対象では新しい配列を返す。
- 移動対象だけ新しい`Node`オブジェクトを返す。
- 無関係なノードは入力と同じ参照を返す。
- `x`または`y`、算出した`dx`または`dy`が有限値でなければ`null`を返す。
- 移動対象の算出座標が1つでも有限値でなければ、部分木全体を更新せず`null`を返す。
- 移動差分がゼロなら、入力順とすべてのノード参照を維持した新しい配列を返す。

ノードIDは`useNodes`が一意に生成する既存契約を前提とする。重複IDの意味付けはこの機能では追加しない。

## アルゴリズム

1. `rootId`のノードを1回の走査で取得する。
2. 同じ走査で`parentId -> childIds`の隣接索引を構築する。
3. `dx = x - root.x`、`dy = y - root.y`を計算し、有限値でなければ`null`を返す。
4. `rootId`から幅優先探索し、移動対象IDを収集する。
5. visited集合により循環と同じIDの再訪を止める。
6. 元の順序で走査し、対象IDの座標へ同じ差分を加える。算出座標が有限値でなければ、部分木全体を更新せず`null`を返す。

計算量は`O(全ノード数 + 到達した子孫数)`、追加メモリは`O(全ノード数)`を上限とする。pointermoveごとに全配列を繰り返し走査する`O(n × depth)`探索は採用しない。

## Hook統合

`useNodes.moveNode`のシグネチャは変更しない。

```ts
moveNode: (id: number, x: number, y: number) => void;
```

内部では`nodesRef.current`を入力に`moveNodeSubtree`を呼び、`null`ならstate更新を行わない。有効な結果は既存の`updateNodes`経由で同期RefとReact stateへ反映する。

`moveNode`は`useCallback`で安定した参照を維持し、初回レンダーから取得したcallbackでも最新のノードと親子関係を使う。同一batchの連続移動は直前の同期Refを基準にする。

## gestureとの契約

ノード移動gestureはツリー構造を知らず、ドラッグ対象ノードの移動先ワールド座標だけを通知する。

gestureはpointer down時の対象ノード座標と開始ワールド座標を固定し、各pointermoveで開始点からの総差分を使って絶対的な移動先を算出する。

`useNodes.moveNode`は最新状態にある対象ノードの現在位置と通知された移動先の差分を、その時点の部分木へ適用する。この組み合わせにより、連続pointermoveで子孫へ総差分を重複加算しない。

現在のUIでは1つのstage bindingが1つのnode gestureを所有するため、ドラッグ中の再接続、削除、別ノード移動は同時実行しない。プログラムから再入した場合も、Hookは呼び出し時の最新ツリーを基準に安全に更新する。

## エラー処理と安全性

- 欠損`rootId`は副作用なしで終了する。
- 入力値、移動差分、各移動対象の算出座標を検証し、`NaN`または`Infinity`を保存しない。
- 不正な循環はvisited集合で探索を停止し、`rootId`から到達できた各ノードを一度だけ移動する。
- 親が欠損した孤立ノードは、`rootId`から到達しない限り移動しない。
- callback例外時のgesture終了・cleanup契約は既存のstage interaction設計を維持する。

## テスト方針

### ドメイン

- 深いツリーをルートから移動し、全子孫の相対配置を維持する。
- 分岐ツリーの中間ノードから、その部分木だけを移動する。
- 葉ノードだけを移動する。
- 無関係なルート、兄弟、孤立ノードの値と参照を維持する。
- `parentId`、width、height、labelを維持する。
- 欠損ノード、非有限入力、有限値同士の差分または加算がoverflowする場合に`null`を返す。
- 入力配列と入力ノードを変更しない。
- ゼロ差分で全ノード参照を維持する。
- 循環データを有限回で処理し、到達ノードを一度だけ移動する。
- 逆順の深いツリーでもノード読み取り回数が線形範囲に収まる。

### Hook

- 親移動で子孫を同じ差分だけ更新する。
- 中間ノード移動で祖先と別部分木を変更しない。
- 同一batchの連続移動が直前の位置を基準にする。
- 初回取得した`moveNode`が最新ツリーを使用する。
- 欠損ノードと無効座標でReact stateを変更しない。
- ノード更新後も`moveNode`のcallback参照を維持する。

### gestureと統合

- 複数回のpointermove後も対象と子孫が正しい総差分だけ移動する。
- 非等倍viewportでワールド座標差分が正しく適用される。
- 4px未満のドラッグでは対象も子孫も移動しない。
- `pointerupoutside`とunbind後は追加移動しない。
- MapStageと実際の`useNodes`を通して、親・子孫・無関係ノードの最終座標を確認する。

対象テストに加えて`client`ディレクトリから`npm run verify`を実行する。

## ロードマップ更新

実装PRのマージ後処理で次を反映する。

- 子孫ノードの一括移動を完了にする。
- Phase 3を完了にする。
- 現在地と次の未完了項目をPhase 4のツリー自動レイアウトへ更新する。

## 対象外

- 自動レイアウト
- ノード同士の重なり回避
- 接続変更時の自動再配置
- 複数ノード選択
- 部分木移動の個別ON／OFF設定
- Undo／Redo

## 完了条件

- 任意の深さと分岐を持つ部分木が相対配置を維持して移動する。
- 葉ノードと既存gestureの操作感を維持する。
- 欠損、不正な循環、非有限入力、座標演算のoverflowで状態を破損しない。
- ノード数に対して線形時間で処理する。
- 新しい外部依存を追加しない。
- すべての自動検証が成功する。
