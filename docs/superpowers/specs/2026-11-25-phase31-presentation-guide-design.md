# Phase 31（072/073）: プレゼンテーションと案内 — 設計

対象カード: [スクラム #36](https://scrum-board-jkcejsb6ka-an.a.run.app/items/36?project=5)  
ROADMAP: 候補072「プレゼンテーションモード」、候補073「案内付き閲覧」

## 決めたこと

1. **スコープ**: 072 と 073 を **1 PR** で実装する。共有のデータモデルは「ツアー（ステップ列）」。
2. **ステップの実体**: 各ステップは既存の `MapViewSnapshot`（viewport・選択・集中・折りたたみ・解像度）を保持する。073 ではステップ専用の短文キャプションを任意で付ける（ノードの詳細メモとは別フィールド）。
3. **永続化**: マップ文書（`MapDocumentV3` / `NodeMapState`）の **任意フィールド** としてツアー定義を保存する。バックアップ・JSON 入出力・競合検出の対象に含める。表示ブックマーク（`localStorage`）とは別系統。
4. **再生 UI**: 明示の「プレゼン開始」で閲覧寄りモードに入る。前後移動・終了。編集用ショートカットと構造変更は抑制する（L-061）。
5. **073 の説明**: ステップ専用キャプションをオーバーレイ／パネルに表示。空ならキャプション領域は出さない（072 相当の見た目）。
6. **編集との関係**: 再生中はノード編集・構造変更・取込などを無効。終了（または Escape）で通常モードへ戻し、再生開始直前の表示状態へ復元できる。
7. **保護モード**: ツアーの編集は不可。再生（開始・前後・終了）は可。

## 1. 目的

作成者が決めた表示状態の列を順番に見せ、必要なら各ステップに短い説明を添えてマップを案内できるようにする。共有サーバーや閲覧専用リンク（Phase 37）は対象外。

## 2. 非目標

- 単体 HTML 書き出し・PDF（Phase 30 残り）
- 同時視聴・リモート同期・認証付き公開
- 自動でステップを生成する AI
- 表示ブックマーク一覧の置き換え（ブックマークは編集用のまま残す）

## 3. データモデル

### 3.1 ツアー

マップあたり **ツアーは最大 1 本**（最初の Phase では複数ツアー管理 UI を持たない）。

```ts
type MapTour = {
  version: 1;
  title: string; // 前後空白除去後、1〜80 文字。空は拒否
  steps: readonly MapTourStep[]; // 永続化時は 1〜50 件。0 件の tour はフィールドごと欠落
};

type MapTourStep = {
  id: string; // ツアー内で一意（新規採番。ノード id と混同しない）
  snapshot: MapViewSnapshot; // Phase 21 と同型
  caption?: string; // 任意。正規化後 1〜500 文字。欠落／空は「キャプションなし」
};
```

`NodeMapState` に任意項目 `tour?: MapTour` を足す（欠落＝ツアーなし）。`version: 3` のまま（L-825: ノード任意属性の濫用ではなく文書級任意フィールド。既存の `relations` / `groups` / `layoutStyle` と同型）。

編集セッションのメモリ上では「タイトルだけあって steps が空」の下書きを許す。**保存・エンコード時**に `steps.length === 0` なら `tour` キーを出さない（空配列の tour は永続化しない）。最後のステップを削除して保存するとツアー定義は消える。

### 3.2 正規化・互換

- デコード時: `tour` がオブジェクトでない・`version !== 1`・`title` 不正 → **`tour` 項目ごと削除**（マップ本体は開く）。
- ステップ配列: 要素がオブジェクトでない／`id` 不正／`snapshot` が適用不能な形 → **そのステップだけ除外**。残ったステップが 0 件、または 51 件超（先頭 50 に切り詰め後でも 0）なら `tour` ごと削除。`caption` 不正はキャプション無しとしてステップは残す。
- スナップショット適用時: Phase 21 と同じく消滅 ID・不可視選択を正規化。
- **文書フィールドとしての引き継ぎ**（ブックマーク localStorage 規則とは別）:

| 操作 | `tour` |
|------|----------|
| 同一マップの自動保存・明示保存・ライブラリバックアップ export / 同一 ID への復元 | **含める** |
| JSON 書き出し（マップ本文）・JSON 全文取込（置換） | **含める**（取込後はデコード正規化） |
| 別名保存（新 ID）・新規マップ作成・テンプレートからの新規 | **含めない**（新文書にコピーしない） |
| 枝の切り出しで別マップ新規 | **含めない** |

### 3.3 Undo

- ツアーの作成・編集・削除（タイトル／ステップ順／キャプション／スナップショット更新）は **1 操作 1 Undo**（文書変更）。
- **再生の開始・ページ送り・終了**は Undo に載せない（閲覧操作。表示ブックマーク適用と同型）。

## 4. 編集 UI（作成者）

- ヘッダーまたは表示系コントロール付近に「ツアー」入口（日本語）。
- できること:
  - ツアー作成（タイトル）／削除
  - 現在の表示状態をステップとして追加（最大 50）
  - ステップの並べ替え・削除・キャプション編集
  - 選択ステップへ「今の表示を上書き」
- ステップが 0 件の下書きでは再生開始を無効（保存時は §3.1 どおり `tour` 欠落）。
- 保護モード: ツアー編集は不可。再生は可（決めたこと 7・§5.1 と一致）。

## 5. 再生 UI（072 + 073）

- 「プレゼン開始」で再生モードへ。画面に:
  - 現在ステップ番号は **1 始まり表示**（例: 3 / 12）
  - 戻る／次へ／終了
  - キャプションがあれば表示（073）
- 開始時: **先頭ステップ**（配列 `steps[0]`、表示は 1 / N）の snapshot を適用（Phase 21 の適用経路を再利用）。適用は **`recordNavigation: false`**（閲覧履歴に積まない）。開始直前の表示は再生セッションのメモリにだけ保持する。
- 次へ／戻る: 対応ステップの snapshot を同様に `recordNavigation: false` で適用。端ではボタン無効。
- 終了 / Escape: 再生モード解除。開始直前の表示状態を復元（やはり閲覧履歴に積まない）。
- キーボード: 左右矢印で前後（再生中のみ。既存の編集ショートカットと衝突しないよう再生中は編集ショートカットを積から外す）。

### 5.1 L-061（再生中に塞ぐ入口）

実装前に `docs/superpowers/specs/2026-11-25-phase31-presentation-guide-inventory.md` を作り、入口ごとに visible / disabled / 拒否 × 保護・競合・関連線／グループ選択・ラベル編集中・アウトラインを列挙する（Phase 28–30 inventory 同型）。

再生モードはメモリ上の排他状態（仮称 `presentation.screen`: `closed` | `playing`。ツアー編集ダイアログは `tourEditor.screen`: `closed` | `open`）。ツアー編集ダイアログ open 中は従来どおり根 `inert`。**再生中は根に `inert` を付けず**、編集ショートカットのみ停止し、パン・ズームと再生バー操作を可とする。

再生中に無効または拒否する代表（詳細は inventory）:

- ノードの作成・削除・移動・ラベル編集・詳細パネルでの属性編集
- 箇条書き／OPML／CSV 取込、JSON 置換、構造変更コマンド
- ツアー定義の編集（再生と編集の同時不可）
- 閲覧を戻る／進む、表示ブックマークの適用・保存・削除（再生中は無効）

再生中も可:

- 次へ／戻る／終了
- 表示のパン・ズームがジェスチャで動いても「次のステップ適用」で上書きしてよい（編集履歴・閲覧履歴には載せない）
- 保護モードでの再生

テスト所有者: 再生ガード＝再生タスク、ツアー編集入口＝編集タスク。

## 6. アウトライン／マップ表示

- 再生 UI は **マップ表示を中心**（アウトラインでも入口 visible にするかは既存表示系コントロールに揃える。推奨: マップ・アウトライン両方で再生開始は visible、編集ダイアログも同位置）。
- アウトライン行の編集は再生中無効。

## 7. 検証の観点

- ステップ追加→保存→再読込→再生で同じ順序・キャプション。
- 不正 `tour` JSON でもマップは開く。
- 再生中に編集入口が無効／拒否（L-061 代表経路）。
- 終了で開始前表示に戻る。Undo はツアー編集のみ巻き戻し、再生ページ送りは巻き戻さない。
- スナップショット内の欠落ノード ID は適用時に安全側へ正規化。
