本 Phase に **合成名は無い**。共有タイトルはローカル `mapTitle`／サーバー `title` の実値。閲覧 404 文言は固定日本語で、トークンや所有者メールを埋め込まない。よって知見 **L-1085 は本 Phase では N/A**。

- [x] inventory 作成（列挙完了・所有者表込み）

判定語（Phase 28–36 同型）:

| 語 | 意味 |
|----|------|
| **非表示** | `visible=false`（控件が `null`、当該画面で到達不可・**未マウント**） |
| **無効** | UI `disabled`・ショートカット無視・操作を実行しない |
| **拒否** | 事前条件不成立で実行しない（未ログイン共有・未共有での更新／追加リンク・排他モード中のダイアログ開始など。Result `ok: false`） |
| **不可** | 設計上到達させない（閲覧頁の編集・書き出し＝**コンポーネント未マウント**。disabled では足りない） |
| **無関係** | 当該条件と交差しない（閲覧トークン頁に MapEditor が無い等） |
| **有効** | 条件を満たせば操作可能 |
| **ログイン導線** | 成功扱いにせず `onLogin`（または同等）へ。Result 成功・リンク表示は出さない（L-001） |
| **即停止** | listening 中に共有ダイアログを開いたら **音声認識を止め**、以降の final でノード追加しない（Phase 36 ダイアログ同型） |

**横断列の読み方（本ファイル共通）**: 各行は **入口** を左に置き、右へ **未ログイン × 所有者・未共有 × 所有者・共有中 × 閲覧トークン頁 × 保護 × 競合 × 学習中 × 再生中 × listening** の順で判定する。セルは「その列の状態が真（または該当）のとき、この入口がどうなるか」を表す（複数列が同時に真なら、いずれかが **拒否**／**無効**／**不可**／**即停止**ならその操作は実行しない想定。ガードは先頭一本化・L-061）。

※競合列: `conflictState === "conflict"` および `externallyDeleted` を含む。  
※学習中: `learningActive === true`。  
※再生中: `presentationPlayback.screen === "playing"`。  
※listening: `listening === true`（Phase 36）。  
※「所有者・共有中」: ローカルメタまたはサーバー一覧で当該 `mapId` に `sharedMapId` があり、かつ `current_revision_id` 非 null（リンク発行可）を想定。未 publish（revision null）は **未共有扱い**（S3 不可）。

**テスト所有者（カテゴリ）**: **Auth／セッション＝Task 1**、**ドメイン・D1/R2＝Task 2**、**Share API＝Task 3**、**所有者 UI・ローカルメタ・notice＝Task 4**、**閲覧シェル＝Task 5**。**E 系＝行別表（§3.2）**。Task 0 は文書のみ。
