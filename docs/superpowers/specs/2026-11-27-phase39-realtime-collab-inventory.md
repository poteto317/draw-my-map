## 判定語

Phase 28–38 同型。本ファイルで使う語:

| 語 | 意味 |
|----|------|
| **非表示** | 控件未マウント／`visible=false`。当該画面で到達不可 |
| **無効** | UI `disabled`・ショートカット無視・監視を止める（操作を実行しない） |
| **拒否** | 事前条件不成立で実行しない（Result `ok: false` または no-op＋必要なら notice） |
| **Yjs経由** | 共同編集中のみ許可。localStorage／従来履歴への直書き禁止。変異は Yjs 文書（必要なら Yjs UndoManager）へ載せる |
| **不可** | 設計上到達させない（**未マウント**。disabled では足りない） |
| **無関係** | 当該状態と交差しない（別ルート・別シェル） |
| **有効** | 条件を満たせば操作可能（**共同編集中列では使わない**） |
| **入力ブロック** | マップ／アウトラインの編集入力を受け付けない（キューしない。設計 決めたこと 12） |

**共同編集中列（L-061・固定語彙）**: §2 の **共同編集中** 列および §2.3 は、セル値を **`無効` / `Yjs経由` / `拒否` のいずれかのみ**とする（読取専用の書き出しなど非変異は表外注記。語彙を増やさない）。

**横断列の読み方**: 各行は **入口**、右へ **idle × connecting × active × reconnecting × error**、末尾に **共同編集中**（=`active` のときの固定語彙）。複数ブロッカーが同時に真なら、いずれかが **拒否**／**無効**／**入力ブロック**なら実行しない（ガードは先頭一本化・L-061）。

※ `共同編集中` 列が本 Phase の「セッション中に塞ぐ／通す」正本。設計 §14・§15「コメント・学習・プレゼン等との交差は inventory で塞ぐ」および決めたこと 9（タブ競合無効化）をここへ落とす。

## 1. UI 状態 ↔ 接続層の対応

型の正本（計画 Task 3 / Task 4）:

- UI: `CollabSessionUi.status` = `idle` \| `connecting` \| `active` \| `reconnecting` \| `error`
- 接続層: `CollabConnectionState` = `connecting` \| `active` \| `reconnecting` \| `closed` \| `error`

| UI (`CollabSessionUi`) | 接続層 (`CollabConnectionState`) | 意味・遷移メモ |
|---|---|---|
| `idle` | （未接続。接続層は持たない／直前が `closed` で復帰済み） | 単独編集。localStorage 正本。タブ競合ガードは従来どおり |
| `connecting` | `connecting` | 開始／join 後の ticket・WS ハンドシェイク中。成功で `active`、失敗で `error` |
| `active` | `active` | Yjs 同期中。文書正本は DO 上の Yjs。タブ競合ガード **無効** |
| `reconnecting` | `reconnecting` | 切断後の再接続試行。**入力ブロック**（キューしない）。切断から **ハード上限 120 秒**以内の成功で `active` |
| `error` | `error`（または `closed` のうち失敗扱い） | 接続失敗・**reconnecting 失敗**（**120 秒超**脱落を含む）の notice 対象（L-166）。成功 UI は出さない。再参加導線 |
| `idle` | `closed`（**意図的 leave／end 成功後**のみ） | 正常終了。`closed` を UI にそのまま出さない |

対応の要約（計画 Task 3・4 と同型・固定）:

| 接続層 | → UI |
|---|---|
| `connecting` | `connecting` |
| `active` | `active` |
| `reconnecting` | `reconnecting` |
| `closed`（leave／end 成功） | **`idle`** |
| `closed`（reconnecting 失敗・120 秒超脱落など異常） | **`error`**（再参加導線。黙って `idle` にしない） |
| `error` | `error` |

`idle` に対応する接続層値は無い（未開始／終了済み）。`connecting` 開始前に接続層オブジェクトを作らない。
