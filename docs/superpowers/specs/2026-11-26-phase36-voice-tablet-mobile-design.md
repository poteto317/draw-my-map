## 1. 目的

外出先やタッチ端末でも、話した内容を素早くノードにし、指で選びやすくし、狭い画面ではアウトライン中心で追記できるようにする。

## 3. 音声入力（090）

排他・入口の可否の **正本は §6 inventory**。本節は要約であり、関連線選択・グループ選択・保護・競合・学習・再生・ダイアログ／パレットなどは inventory 行を実装・テストの正とする。

### 3.1 入口

- ヘッダーの「音声入力」**トグル 1 つ**（ON＝聞き取り中）。コマンドパレット `voice-input-start` / `voice-input-stop`（日本語ラベル）は同じ `listening` 状態を ON／OFF する。
- 開始不可（inventory どおり）: 保護モード・競合中・学習モード中・プレゼン再生中・ダイアログ／パレット開中・関連線／グループ主選択中など。拒否は日本語 reason（L-061・L-1211）。
- 未対応ブラウザ（`SpeechRecognition` 系が無い）は押下で拒否通知のみ（成功扱いにしない。L-001）。
- 聞き取り**開始後**にダイアログ／パレット／学習／再生など inventory 上の排他状態へ入ったら **即座に認識を停止**し、その後の確定結果ではノードを追加しない（停止通知を出す）。

### 3.2 認識セッション

- API には `continuous: false`、`interimResults: true` を渡す。
- **セッションループ**: ユーザーがトグル OFF（または stop）するまで、1 回の `isFinal` 確定のたびに 1 ノードを追加し、続けて同じ認識インスタンスを **自動で再 `start`** する（バックグラウンド常時聞き取りではない。UI が明示的に ON の間だけの明示セッション）。
- 中間結果（非 final）は **ヘッダー近傍の一時ラベルのみ**に出す。live 通知は確定追加の成功／拒否／停止／エラーに限る（L-166）。
- 空・空白のみの final は追加しない（履歴なし・通知なし）。
- 停止・エラー・`nomatch` は通知し、部分確定が無ければノードを作らない。エラー時は listening を OFF にする。
- 同時に複数セッションは持たない。**聞き取り中の再開始（トグル ON の再押下・palette start）は no-op**（成功扱いで追加通知しない。§7）。停止してから開始したい場合は先に OFF／stop する。

### 3.3 ノード追加契約

正本 API は既存の **`insertForest`**（`InsertForestResult`）。空ラベル用の `addChildNode` → 別途 `updateNodeLabel` の **2 段は使わない**（1 Undo と L-048／L-001 のため）。

| 選択状態 | 追加 |
|----------|------|
| 主選択ちょうど 1（ノード） | `insertForest([{ label: 正規化テキスト, … }], { kind: "child", parentId })` |
| 未選択 / 複数選択 / 関連線・グループ主選択（開始は inventory で拒否だが、確定時点で選択が変わった場合） | `insertForest([{ label }], { kind: "root" })` |

- ラベル正規化: 前後空白除去、制御文字除去、最大は既存ラベル上限。
- 結果型 `VoiceNodeAddOutcome` は `InsertForestResult` をラップまたは同一形とし、呼び出し元が success / reason を見る（§7）。
- 追加成功は **1 Undo**（1 回の `applyTreeChange`）。失敗は通知し Undo なし。
- 追加後は新ノードを選択し、マップ表示時は既存フォーカス経路で中央寄せ（無ければ選択のみ）。

### 3.4 アウトライン表示中

- 同じ追加契約。アウトラインでも音声入口を使える。マップ専用にはしない。

## 4. タブレット向け操作（091）

### 4.1 ヒット領域

- Pixi ノードのポインタ判定に、タッチ時の **追加パディング**（論理 px。例: 8〜12）を適用する。マウス／ペンは現行のまま（`pointerType === "touch"` のときだけ広げる）。
- ヒット拡大は描画矩形を変えない（見た目のノードサイズは据え置き）。

### 4.2 長押しコンテキスト

- タッチでノード上の **長押し**（例: 450–550ms、移動許容小さい）で既存コンテキストメニューを開く。マウスの右クリック経路は変更しない。
- 長押し確定前に移動閾値を超えたらパン／ドラッグへ（既存ジェスチャと競合しないよう coordinator 側で優先順位を定義）。

### 4.3 誤タップ抑止

- ダイアログ／メニュー閉鎖直後の pointer／dblclick 無視窓は既存（L-060 / L-408 系）を維持し、タッチでも同じ共有 `dialogMouseClickedAtRef` を通す。
- ピンチ中・2 本指中は単指の選択・コンテキストを開始しない。**既存 `touchGestureCoordinator` の挙動を正本とし、本 Phase では coordinator 本体を拡張しない**。契約はユニット／統合テストで固定する（足りなければ最小のガード追加のみ）。

## 5. スマートフォン向け簡易編集（092）

### 5.1 幅の定義

- 狭幅の正本は定数 **`NARROW_VIEWPORT_MAX_PX = 767`**（`matchMedia('(max-width: 767px)')` と同義＝レイアウト幅 **768px 未満**）。他節・実装・テストはすべてこの定数を参照する。

### 5.2 既定表示

- 狭幅に入ったとき、ユーザーが **そのマップ編集セッションで明示的にマップへ切り替えていない**場合は `viewMode` を `outline` にする。
- 狭幅でユーザーがマップへ切り替えたら、セッションフラグ `userChoseMapOnNarrow` を立て、その選択を尊重する（幅が広→狭に戻っても outline へ上書きしない）。このときの「切替しない」は **スキップ（通知なし）**。
- **`userChoseMapOnNarrow` のリセット契機**（これ以外ではリセットしない）:
  - ライブラリ等で **別マップ文書**へ切り替わり `MapEditor` が再マウントされたとき（`mapId` 変更）
  - 保護モード移行などで編集画面全体が作り直されたとき
  - **含まない**: `viewMode` の map↔outline 切替そのもの、ウィンドウ幅の変化だけ
- 広幅では現行どおり（既定マップ）。狭→広で強制マップ復帰はしない（ユーザーの outline 選択を維持）。

### 5.3 アウトラインでの追記

- 既存のアウトライン編集（Enter で兄弟、Tab 階層など）を主経路とする。
- 狭幅ヘッダーは **横スクロール 1 方式**（折りたたみメニューは本 Phase 外・#63）。先頭付近に **表示モード切替・音声トグル・保存状態**が常に到達できる並びを維持する。

### 5.4 マップ表示（狭幅）

- 手動でマップへ切り替えた場合、パン／ズーム／選択は既存どおり。仮想キーボードでビューポートが縮む場合の特別補正は本 Phase 外（既知の制限）。

## 6. 入口インベントリ（L-061）

実装 Task 0 で `docs/superpowers/specs/2026-11-26-phase36-voice-tablet-mobile-inventory.md` を作る。**Phase 35 §7.1 / Phase 31 同型**で、新状態 `listening` を含む全危険入口の横断表を正本とする（下表の V/T/M は代表サンプルであり網羅ではない）。

必須行カテゴリ:

- **V**: 音声開始／停止／パレット／確定→ノード追加
- **T**: タッチヒット／長押し
- **M**: 狭幅 outline 既定／マップ手動切替
- **E**: 既存の構造編集・取込・AI・学習開始・プレゼン開始・コマンドパレット他操作・`editorShortcutsEnabled` 積など（`listening` 中に塞ぐ／許すを全行で決める）

| ID | 入口（サンプル） |
|----|------|
| V1 | 音声トグル ON |
| V2 | 音声トグル OFF / stop |
| V3 | パレット voice-input-start/stop |

| T2 | タッチ長押し→コンテキスト |

## 7. 成否と通知（L-001 / L-166）

| 操作 | 成功 | 失敗・拒否・スキップ |
|------|------|----------------------|
| 音声開始 | 聞き取り中表示 | 未対応・排他・保護など日本語 reason |
| 聞き取り中の再開始 | — | **no-op**（通知なし） |
| 排他状態への遷移中の強制停止 | listening OFF + 停止通知 | — |
| 確定追加 | ノード追加 + 1 Undo | 空文はスキップ（通知なし）。追加失敗は通知、Undo なし |
| 音声停止 | アイドルへ | 既に OFF なら no-op |
| 長押しメニュー | メニュー表示 | 閾値超過でジェスチャへ（失敗通知なし） |
| 狭幅既定切替 | outline へ | `userChoseMapOnNarrow` 中は **スキップ（通知なし）** |

同一内容の連続通知は既存の revision-scoped / live 通知の慣行に合わせ、読み上げ可能にする（L-166）。

**通知のクリア（L-166）**: 次のとき古い音声／狭幅関連 notice を消す — listening OFF、`mapId` 変更（再マウント）、`documentRevision` が進んだ成功操作の直後（成功通知は残してよい）、編集画面破棄。選択変更だけでは拒否 reason を消さない（短時間の再試行のため）。
