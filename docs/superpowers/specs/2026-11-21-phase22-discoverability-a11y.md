# Phase 22: 操作の発見性とアクセシビリティ 設計書

作成日: 2026-11-21。対象: ITEM-027 / ROADMAP Phase 22 の 2 項目（候補020「コマンドパレット」、候補021「キーボード操作と読み上げ対応」）。前提: Phase 10（ノード検索）・Phase 15（アウトライン）・Phase 19（横断検索ダイアログ）・Phase 21（閲覧ナビ）までの操作入口・ダイアログ・フォーカス契約。状態: 推奨案を採用済みとして設計確定（設計レビュー第1・2周の指摘を反映済み）。

---

## 1. 背景と目標

マップ編集の操作が増え、ヘッダーの `operationControls` にボタンが直書きで増え続けている。マウスで探しにくい操作を、名前検索で実行できるようにする。あわせて、キャンバス（Konva）上にフルな ARIA ツリーを載せず、既存のアウトライン表示を非キャンバスの構造ナビ／編集の主経路として強化し、キーボードと読み上げで移動・編集できるようにする。

成功条件:

1. Ctrl/Cmd+K でコマンドパレットを開き、操作名の部分一致で候補を絞り、既存の操作 API を第 2 入口として実行できる。
2. 破壊的操作は既存の確認ダイアログを経由し、確認内容を見ないまま確定できない。
3. アウトラインで階層の移動・選択・ラベル編集・構造変更が、読み上げ可能な DOM だけで完結する（行フォーカスから Tab でツールバーへ到達する現行経路は退行させない）。
4. パレット実行結果は閉じた後も残る通知枠で、アウトラインの選択変化は `aria-live` で伝わる。
5. 既存の `editorShortcutsEnabled` / `inert` / `useDialogFocusTrap` / `isEditableTarget` / `treeEditShortcutGuard` / ヘッダーへのフォーカス復帰（L-155）を壊さない。

## 2. 要件（受け入れ条件）

### 2.1 コマンドパレット（候補020）

- Ctrl（Windows/Linux）または Cmd（macOS）と K の同時押しでパレットを開く。IME 変換中（`isComposing` または `keyCode === 229`）は開かない。入力欄など `isEditableTarget` が真のときは開かない（既存ショートカットと同じ）。
- 既存のダイアログまたは保存確認が開いている間（`editorShortcutsEnabled === false` の間）は起動しない。パレット自身が開いている間も `editorShortcutsEnabled` は偽にし、根の `inert` を付ける。
- パレット内に検索欄と候補一覧がある。検索語は NFKC＋小文字化のあと前後空白を除き、コマンドの表示名・別名・カテゴリ名に対する部分一致で絞る（ノード検索と同じ正規化）。
- **空クエリ**: 推奨セット（カテゴリ順・登録順。モード不一致のコマンドは除外）。モード一致だが選択不足などで不可のものは残し、`aria-disabled`＋理由を出す。最大 50 件。
- **非空クエリ**: 部分一致したものをカテゴリ順・登録順で最大 50 件。一致した不可も残し、`aria-disabled`＋理由。
- Enter でハイライト中の実行可能なコマンドを実行する。不可候補では実行せず、拒否理由を一覧表示とパレット内 live に出し、パレットは開いたまま。Escape・オーバーレイ・閉じるボタンで閉じ、フォーカスを開く直前の要素へ戻す（`closeReason: "dismiss"`、`focusRequest: restore-opener`。フォールバック列は §5.1）。一致件数が上限超過のときは「他 N 件」（`overflowCount`）を示す。
- 実行は常に既存操作のコア関数へ同期委譲する（ヘッダーボタンの enabled ガードを迂回し、パレット側で可否を再評価。閉じてから遅延実行しない）。ドメイン操作の新しい実装経路を作らない。即時成功の閉鎖は `closeReason: "execute-immediate"`（focusRequest なし）。
- 破壊的操作は、ヘッダー／既存入口が確認ダイアログを開くものと同一集合とする。パレットは各コマンドの `open*` のみを呼び、確定は既存ダイアログの確認 UI を通す。確認内容が見えない状態で承認ボタンだけが押せる経路は作らない（L-688）。`opensDialog` は次ダイアログ open のメタであり、L-688 対象と同一ではない。
- 即時実行の成功・失敗は、閉じた後も残る既存の `MapOperationNotice` 系統へ出す。パレット内 live は開いたままの拒否・無効専用。
- ヘッダーに個別操作ボタンをこれ以上増やさない方針とする。本 Phase でパレット起動用のヘッダーボタン「コマンド」を **必須で 1 つ**置く（`operationControls` 先頭、`aria-keyshortcuts` に Ctrl+K / Meta+K）。`editorShortcutsEnabled` 偽や他ダイアログ中はヘッダーからも起動しない。既存ボタンの削減はこの Phase の必須ではない。

### 2.2 キーボード操作と読み上げ対応（候補021）

- キャンバス（`MapStage` / Konva）に `role="tree"` / `treeitem` などのフル ARIA ツリーは追加しない。キャンバス領域は従来どおりポインタ操作の主領域とし、読み上げの構造ナビの主経路はアウトラインとする。キャンバスコンテナには `aria-label="マップキャンバス"` を付与する。
- アウトライン表示（`viewMode === "outline"`）で、既存の ↑↓ / Home / End / Enter・F2（編集開始）に加え、次を満たす。
  - 行ボタンのアクセシブルネームに「階層 N・ラベル」が含まれる（現状維持）。
  - 行の選択がキーボードまたはクリックで変わったとき、`aria-live="polite"` のステータス領域が「N 件中 M 件目、階層 D、ラベル」を伝える。同じ ID の再選択では文言を変えない。視覚的な追加バナーは出さず、既存の説明文付近のライブリージョンを更新する。
  - **Tab によるツールバー到達は現状維持（退行禁止）**。パレットから同操作を呼べることは追加の到達手段であり、Tab 経路の代替にはしない。
  - ラベル編集中の Enter（確定）／Escape（取消）／IME・リピート抑止は現状契約を維持する。
- マップ表示からアウトラインへ、およびその逆へ、パレットまたは既存の表示切替コントロールで移れる。切替後のフォーカス優先列:
  - アウトラインへ: `(1) 選択行 (2) 先頭行 (3) ルート追加`
  - マップへ: キャンバスコンテナ（既存の `tabIndex` 契約）
- パレットを含むダイアログ表示中は、アウトライン／マップのショートカットは動かない（`editorShortcutsEnabled` と `inert`）。
- Alt 系のキャンバス用ツリー編集ショートカットは、現状コードの有無にかかわらず、本 Phase では新規割当も削除もしない（現状スナップショットを回帰で固定）。

## 3. 非目標

- キャンバス上の Konva ノードへの ARIA ツリー／ライブ領域の付与、スクリーンリーダー専用のキャンバス座標読み上げ。
- コマンドパレット用の新規 npm 依存（cmdk 等）。既存のダイアログ＋リストで実装する。
- ヘッダー `operationControls` からの既存ボタン一括削除・情報アーキテクチャの大規模整理（発見性の第 2 入口を足すことが主目的）。
- コマンドのユーザー定義・並び替えの永続化、コマンド履歴の永続保存、クラウド同期。
- 自然言語でのあいまい実行、AI 提案、マクロ／複数コマンドの一括キューイング。
- アウトラインへの DnD、独自折りたたみ、フィルタ表示、複数選択（Phase 15 の非目標を踏襲）。
- 新しい保存形式、`documentRevision` の意味変更、Undo スタックへの「閲覧専用操作」の混入。
- スマートフォン専用のジェスチャー UI、国際化（文言は既存どおり日本語）。

## 4. 決めたこと（採用済み）

1. **起動キー**: Ctrl/Cmd+K。`editorShortcutsEnabled` が偽の間、および `isEditableTarget` / IME 変換中は無効。
2. **パレットの役割**: 既存操作 API の第 2 入口。ヘッダーボタン増殖の抑制。破壊的操作は既存確認ダイアログ経由。
3. **a11y 方針**: キャンバスにフル ARIA tree は作らない。`aria-label="マップキャンバス"` のみ付与。アウトラインを構造ナビ／編集の主経路として強化。即時実行結果は閉じ後も残る `MapOperationNotice` へ、拒否はパレット内 live へ。
4. **既存契約の遵守**: `useDialogFocusTrap`、根の `inert`、`treeEditShortcutGuard`、`isEditableTarget`、ダイアログ閉鎖後のフォーカス復帰（L-155）を維持・拡張する。
5. **コマンド定義の置き方**: 表示名・別名・カテゴリ・可否判定の純関数カタログと、`MapEditor` 側の実行ワイヤリングを分ける。実行本体は既存ハンドラへの委譲のみ。
6. **不可コマンドの表示**: 空クエリは推奨セット（モード不一致は除外）。モード一致だが選択不足などで不可のものは残し、`aria-disabled`＋理由。非空は一致した不可も残す。発見性を優先し、モード一致の不可を一覧から消さない。
7. **他ダイアログを開くコマンド**: 同一同期処理内でパレット閉（`closeReason: "execute-dialog"`）→ 次ダイアログ `open` を連続させ、描画上も両方が閉のフレームを作らない（次ダイアログの `screen !== "closed"` が立つまで `editorShortcutsEnabled` を偽のまま）。直前要素へのフォーカス復帰は行わず、開いた先のダイアログのトラップに渡す。
8. **永続化**: パレットの開閉・検索語・ハイライト位置はセッション内 UI 状態のみ。マップ JSON・localStorage のマップ本文・ライブラリメタは変更しない。
9. **ヘッダー起動ボタン**: 「コマンド」を必須で 1 つ置く。
10. **クローズ理由**: `closeReason: "dismiss" | "execute-immediate" | "execute-dialog" | "stale"`（§5.1）。即時成功は `execute-immediate`（focusRequest なし）。dismiss/stale は restore-opener。

## 5. コマンドパレット仕様

### 5.1 UI とフォーカス

- コンポーネント名の目安: `CommandPaletteDialog`（`components/layout/`）。状態遷移の純関数は `commandPaletteState.ts`、起動ショートカットは `commandPaletteShortcut.ts` + `useCommandPaletteShortcut`（既存 `*Shortcut.ts` + `use*` の形）。
- 状態は `commandPalette.screen: "closed" | "open"` に統一する。
- ダイアログは `role="dialog"`、`aria-modal="true"`、タイトル「コマンドパレット」。検索欄は `aria-controls` で一覧に結び、一覧は `role="listbox"`、各候補は `role="option"`、ハイライトは **listbox + `aria-activedescendant` のみ**（フォーカスは検索欄。roving tabindex は使わない）。
- 表示中は `useDialogFocusTrap` を使い、Escape で閉じる。オーバーレイの外側クリックは既存ダイアログと同じ（ドラッグで誤閉じしない）規則に合わせる。
- 開いた直後のフォーカスは検索欄。
- **クローズ理由とフォーカス**:
  - `dismiss`（Escape／オーバーレイ／閉じるボタン）: `focusRequest: restore-opener`。開く直前の `document.activeElement` を控え、次の優先列で復帰する。`(1) 開く直前要素（DOM に残存・無効でない・可視） (2) ヘッダー「コマンド」ボタン (3) viewMode に応じ、マップならキャンバスコンテナ、アウトラインなら選択行 → 先頭行 → ルート追加`（L-155 / L-157）。
  - `execute-immediate`（即時成功でパレットを閉じる）: `focusRequest` なし。表示切替後のフォーカスは §2.2 の切替列（アウトライン: 選択行 → 先頭行 → ルート追加、マップ: キャンバスコンテナ）。その他の即時操作は既存操作と同じフォーカス先に任せる。
  - `execute-dialog`（他ダイアログを開くコマンド実行）: `focusRequest` なし。直前要素への復帰は行わず、同一同期処理末尾の `open` 先トラップだけにフォーカスを渡す。
  - `stale`（`mapId` / `documentRevision` 変化など）: `dismiss` と同じ `restore-opener` フォールバック列を使う。
- 閉じるボタンは必須（`onDismiss`）。
- `MapEditor` の `editorShortcutsEnabled` 積に `commandPalette.screen === "closed"` を足す（L-061）。パレットはルートの `inert` 対象の外に描画する（他ダイアログと同じ）。ヘッダー「コマンド」も `editorShortcutsEnabled`／他ダイアログ中は起動しない。

### 5.2 検索とキーボード

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 候補間のハイライト移動（不可コマンドも移動可）。端で止まる |
| Home / End | 先頭／末尾候補 |
| Enter | ハイライトが実行可能なら実行。不可なら実行せず拒否を live で伝え、パレットは開いたまま |
| Escape | 閉じる（`closeReason: "dismiss"`） |
| Tab | ダイアログ内フォーカストラップ（検索欄と閉じるボタン等）。一覧は activedescendant 方式とし、オプションへ Tab で入らない |

検索の照合:

- 正規化: `text.normalize("NFKC").toLowerCase()` のあと trim（ノード検索と同じ）。
- 対象フィールド: 表示名、別名配列、カテゴリ名。
- **空クエリ**: 推奨セット（カテゴリ順・登録順。モード不一致のコマンドは除外）。モード一致だが選択不足などで不可のものは残し、`aria-disabled`＋理由。最大 50 件。
- **非空クエリ**: 部分一致したものをカテゴリ順・登録順で最大 50 件。一致した不可も残し、`aria-disabled`＋理由。一致総数が 50 を超える場合は「他 N 件」を status で示す（L-160 の考え方）。

### 5.3 コマンドカタログ

#### 第1版の必須境界

- **第1版の必須コマンド**: 既存ヘッダー `operationControls` およびアウトラインツールバーと同等の操作 ＋ 確認ダイアログ系の `open`（ラベル一括置換・枝移動・分割・統合など、既存入口が確認 UI を開くもの）。これらは完了条件・必須テストの対象。第1版カタログ定数は必須 ID のみ。
- **後続（第1版カタログ外）**: 入出力（JSON／画像／Markdown 等）、ライブラリ入口、閲覧ナビ（戻る／進む）など。プランでは必須表と後続参考表を分け、opensDialog（次ダイアログ open）と L-688（破壊的確認必須）を注記で分離する。

#### カタログ表

カテゴリと代表コマンド。可否は既存コントロールと同じ条件（選択なし・端・保護モード・競合・表示モード不一致など）を再利用する。**確認 UI** 列は、パレットが呼ぶのが `open*` のみで確定は既存ダイアログ側、という機械的規則に従う（例外 ID があれば列挙する。現状の例外なし）。

| カテゴリ | コマンド例（表示名） | 実行の委譲先 | 確認 UI | 第1版 |
| --- | --- | --- | --- | --- |
| 表示 | マップ表示へ切替 / アウトライン表示へ切替 | `changeViewMode` | なし（即時） | 必須 |
| 表示 | 全体に合わせる / 選択に合わせる / 枝に集中 / 集中を終了 | 既存 viewport / focus ハンドラ（マップ時のみ可） | なし（即時） | 必須 |
| 表示 | 閲覧を戻る / 閲覧を進む | `viewNavigation.travel` | なし（即時） | 機構あり・必須テスト外 |
| 表示 | 枝を一括展開 / 枝を一括折りたたみ | `branchCollapse.setSubtreeCollapsed` | なし（即時） | 必須 |
| 編集 | 元に戻す / やり直す | `undo` / `redo` | なし（即時） | 必須 |
| 編集 | 枝を複製 / ノードだけ削除 / 親を挿入 / 兄弟を上へ・下へ / 階層を下げる・上げる | 既存 duplication / nodeOnlyDeletion / parentInsertion / siblingReorder / indent | なし（即時。既存確認が無いもの） | 必須 |
| 編集 | ラベルを一括置換… / 枝を別マップへ移動… / ノードを分割… / ノードを統合… | 各 `open*`（ダイアログ） | 既存確認ダイアログ経由（パレットは open のみ） | 必須 |
| 検索 | マップ内検索へフォーカス / 全マップ検索… | 検索欄 focus または `openCrossMapSearch` | なし／ダイアログ open | 必須 |
| アウトライン | ルート追加 / 子を追加 / 兄弟を末尾に追加 / ラベル編集 | `outlineActions`（アウトライン時のみ。マップ時はモード不一致で空クエリから除外、非空なら不可＋理由） | なし（即時） | 必須 |
| 入出力 | JSON 書き出し / JSON 読み込み / PNG・SVG 書き出し / Markdown・テキスト書き出し / 箇条書き取り込み… | 既存 persistence / export / outlineImport | 既存どおり（取込系は open） | 機構あり・必須テスト外 |
| ライブラリ | マップ一覧… など既存ヘッダーのライブラリ入口 | 既存 `mapControls` の open | 既存どおり | 機構あり・必須テスト外 |

エイリアス例: 「Undo」→「元に戻す」、「フィット」→「全体に合わせる」、「Cmd+K」は起動専用でカタログには載せない。

コマンド ID は安定した英小文字の定数（例: `view.outline`）とし、表示名の変更で ID を変えない。複合キーを文字列連結で作らない（必要ならタプルか単一 ID）。

並べ替え・インデント等の構造変更をパレットから委譲する場合も、基準は配列上の `parentId` 関係であり、キャンバスの Y 座標順ではない（L-472）。

### 5.4 実行と結果通知

1. 実行直前に、カタログの可否判定を最新の props／状態で再評価する（開いている間に選択や revision が変わった場合に備え、L-037 の精神で古い可否を信用しない）。閉じてから遅延実行しない（閉じた後に古いクロージャが走らない）。
2. 委譲先は既存ハンドラと同様、正本 `nodes` と全 ID 集合の可用性だけを使う。表示投影配列を保存・編集 API に渡さない（L-015）。
3. 不可ならパレット内 live 領域へ理由を出し、閉じない。
4. 可なら、既存ヘッダーボタンの `disabled`／`enabled` ガードを迂回し、**既存コア関数へ同期委譲**する（閉じてから遅延実行しない）。
   - 即時完了系（Undo、フィット等）: 既存 notice があればそれを使い、無ければ「『表示名』を実行しました」を **閉じた後も残る** `MapOperationNotice` 系統へ polite に出す。パレットは `closeReason: "execute-immediate"` で閉じる（`focusRequest` なし。表示切替は §2.2 の切替列）。パレット内 live には成功を載せない。
   - ダイアログ開始系: `closeReason: "execute-dialog"` でパレットを閉じ、同一同期処理末尾で `open*`。追加の成功文言は出さない（先のダイアログが担う）。直前要素へのフォーカス復帰はしない。
5. ハンドラが既存どおり失敗 notice を出す場合は、それを優先し、パレット用の重複成功文言は出さない。

## 6. キーボード・読み上げ仕様（アウトライン強化）

### 6.1 現状の維持

- 平坦な `<ol>` + 行 `<button>`。独自 ARIA tree は使わない（Phase 15 契約）。
- 折りたたみ・解像度に依存せず全ノードを表示。構造操作の ID 集合は全 `nodes`（L-015: 表示投影を正本操作に渡さない）。
- 兄弟順・インデントの基準は配列上の `parentId` 関係であり、キャンバスの Y 座標順ではない（L-472）。

### 6.2 追加する読み上げ

- `OutlineEditor` 内に常設の `role="status"` / `aria-live="polite"` 領域（視覚的には `sr-only` 相当でよい）を 1 つ置く。
- 更新タイミング: キーボードまたはクリックで選択行が変わったとき。同じ ID の再選択では文言を変えない（無駄な再読み上げを避ける）。
- 文言テンプレート: `全{total}件中{index}件目、階層{depth}、{label}`。空マップは更新しない。ラベルは `getNodeDisplayLabel`。
- パレットからのアウトライン操作成功時は、既存の treeEdit 通知（閉じ後も残る枠）を使い、アウトライン status と矛盾する二重の長文は避ける（短い選択案内のみアウトライン側）。

### 6.3 キーボード操作の範囲

| 状況 | キー | 動作 |
| --- | --- | --- |
| 行フォーカス | ↑↓ Home End | 既存どおり移動・選択・フォーカス移動 |
| 行フォーカス | Enter / F2 | 既存どおり編集開始（リピート無視） |
| 行フォーカス | Delete / Backspace | 割り当てない（誤削除防止。削除はツールバーまたはパレット） |
| 編集中 | Enter / Escape | 既存どおり確定／取消 |
| どこでも（有効時） | Ctrl/Cmd+K | パレット |

Alt 系のキャンバス用ツリー編集ショートカットは、本 Phase では新規割当も削除もしない（現状維持・回帰固定）。アウトライン固有の構造変更の正はツールバー（Tab 到達を退行させない）とパレット（追加手段）とする。

### 6.4 マップ（キャンバス）側

- コンテナに既存どおりフォーカス可能領域を保つ。
- 読み上げ用に子ノードの tree 役割は付けない。キャンバスコンテナに `aria-label="マップキャンバス"` を付与し、構造の詳細はアウトラインへ誘導する（表示切替またはパレットの「アウトライン表示へ切替」）。

## 7. 既存部品との接続

### 7.1 `MapEditor`

- `commandPalette` 状態は `screen: "closed" | "open"` と open/close（`closeReason` 付き）/consumeFocus を所有する。
- `editorShortcutsEnabled` の積に `commandPalette.screen === "closed"` を追加。`useCommandPaletteShortcut({ enabled: editorShortcutsEnabled, onOpen })` を登録。
- カタログの実行クロージャに、現在の `viewMode`・選択・各 dialog open・outlineActions・viewNavigation などを渡す。
- `operationControls` の JSX は残し、パレットは同じハンドラを共有する。パレット専用の別実装を作らない。
- ヘッダー `operationControls` 先頭に「コマンド」ボタンを 1 つ置く（必須）。起動はショートカットと同様に `editorShortcutsEnabled`／他ダイアログ中でゲートする。

### 7.2 ダイアログ群

- `CommandPaletteDialog` は `BranchMoveDialog` / `CrossMapSearchDialog` と同型: `useDialogFocusTrap`、`dialogMouseClickedAtRef` 更新、ルート外描画、`documentRevision` やマップ切替で開いたままにしない（開いた時点の mapId / revision を控え、変わったら `closeReason: "stale"` で閉じる。L-037）。

### 7.3 ショートカットガード

- 起動判定は `isEditableTarget` を共用。独自の入力判定を増やさない。
- パレット検索欄は editable なので、開いている間に他ショートカットが誤爆しないことは `editorShortcutsEnabled === false` で担保（二重の局所ガードに頼らない。L-061）。

### 7.4 通知

- 既存 `MapOperationNotice` / `MapOperationNoticeList`（status=polite、error/warning=assertive）を、即時実行の成功・失敗に使う（パレット閉鎖後も残る）。
- パレット内の `role="status"` は開いたままの拒否・無効案内専用（閉じると消える）。

### 7.5 保護モード・競合（L-061）

- 保護モード・競合・外部削除時の可否は、ヘッダー／既存ダイアログと同じ表にパレットコマンド行を足す。マップ切替や永続化を伴うコマンドは既存どおり拒否または無効理由を示す。
- パレットだけが保護モードで余計な書き込みをしない（読み取り系・表示切替・現在マップ内の許可済み編集のみ）。

### 7.6 パレット open 時の入口表（L-061）

パレット `screen === "open"` のあいだ、既存入口を機械的に列挙し同じ値で止める。既存ダイアログ（BranchMove / LabelReplace / CrossMap 等）の入口洗い出しを grep で写す。結合テストは「積から `commandPalette.screen === "closed"` を外すと落ちる」形で固定する。

| 入口 | パレット open 時 |
| --- | --- |
| `editorShortcutsEnabled` 積（履歴・ツリー編集・ノードキー・閲覧・横断検索起動など） | 偽（`commandPalette.screen === "closed"` を積に含める） |
| ルートの `inert` | 付与（パレットはルート外） |
| `changeViewMode`（ヘッダー等） | 既存ダイアログと同様に止める／不可 |
| `outlineActions` の有効条件 | 既存ダイアログと同様 |
| `useMapHistoryShortcuts` ほか各 `use*Shortcut` | `enabled: editorShortcutsEnabled` 経由で停止 |
| `mapId` / `documentRevision` 変化 | パレットを `stale` で自動 close |
| `persistence.isConfirmOpen` | 保存確認中はパレットを開かない（既存と同様の同時表示禁止） |
| `dialogMouseClickedAtRef` | パレットの `onMouseClick` で更新 |
| ヘッダー「コマンド」ボタン／Ctrl+K | 開中は再オープンしない（既に open） |
| パレット → 他ダイアログ連鎖 | 同一同期処理で閉→開。中間で shortcuts を真にしない |

## 8. エラー・フォーカス・世代

| 状況 | 扱い |
| --- | --- |
| 実行時に対象ノード消失 | 既存 API の失敗／notice。パレットは閉じ済なら通知枠、開いたままなら live |
| Undo/Redo・JSON 取込で `documentRevision` 進行 | 開中パレットは `stale` で閉じ、フォーカスは §5.1 のフォールバック列（L-037, L-155） |
| パレット開中に他ダイアログをコードから開こうとした | パレットを先に閉じる単一経路だけを許す（`execute-dialog`） |
| 閉じた要素への focus（`dismiss` / `stale`） | §5.1 の番号付き優先列（L-157） |
| `execute-immediate` | focusRequest なし。表示切替は §2.2 列 |
| `execute-dialog` | 直前要素復帰なし。open 先トラップへ |
| 確認ダイアログの承認 | 既存 UI で内容が見えるときだけ押せる契約を維持（L-688）。パレットから確認をスキップする API は作らない。`opensDialog` は次ダイアログ open のメタであり L-688 対象と同一ではない |
| 表示用ノード配列 | 保存・複製・削除・構造変更に渡さない（L-015） |

## 9. テスト観点

### 9.1 単体

- `commandPaletteShortcut`: Ctrl/Cmd+K、editable／IME／enabled 偽で発火しない。
- カタログ検索: NFKC・大小文字・表示名・別名・カテゴリ名・空クエリ（モード不一致除外・モード一致の不可残存）・上限 50・非空の不可残存。
- 可否の純関数: 選択なし・outline/map 不一致・端の並べ替えなどが既存コントロールと同じ結果。

### 9.2 部品

- `CommandPaletteDialog`: フォーカストラップ、Escape、activedescendant、不可の Enter（live＋開いたまま）、`dismiss` 後の `document.activeElement`。
- `OutlineEditor`: キーボード／クリックの選択変更で live 文言が更新される、同じ ID では変えない、ラベル空の表示名。

### 9.3 結合（MapEditor）

- ヘッダー「コマンド」ボタン 1 つでパレットが開く。
- パレット開で `editorShortcutsEnabled` が偽、根が `inert`、履歴ショートカットとツリー編集ショートカットが止まる（L-061）。入口表の各行。積から `commandPalette.screen === "closed"` を外すと落ちるテスト。
- パレットから Undo／表示切替／ダイアログ open が既存ボタンと同じハンドラに届く（スパイまたは notice）。即時成功は `MapOperationNotice` 側に残る。
- ラベル一括置換などをパレットから開いたとき、確認ダイアログを経由せず確定できない。連鎖後の `activeElement` が置換ダイアログ内（直前要素へ戻らない）。
- 同一同期処理の閉→開のあいだに履歴ショートカットが発火しない。
- `documentRevision` 変更でパレットが `stale` 閉じする。
- アウトラインへ切替後、フォーカスは選択行 → 先頭行 → ルート追加の順。
- キャンバスコンテナに `aria-label="マップキャンバス"`。
- アウトライン行から Tab でツールバーへ到達できる（退行禁止）。

### 9.4 回帰で触る既存

- `useDialogFocusTrap`、`editableTarget`、`treeEditShortcutGuard`、Outline の ↑↓／編集、Phase 21 の閲覧ショートカット、CrossMap 検索ショートカット、Alt 系ショートカットの現状スナップショット。

## 11. 未決事項の確定（推奨のまま採用）

設計時点で残していた選択は、次のとおり推奨案で確定する。プレースホルダーは残さない。

| 項目 | 確定内容 | 理由 |
| --- | --- | --- |
| ヘッダーの起動ボタン | 「コマンド」を必須で 1 つ置く | キーボードを知らない利用者向けの発見性 |
| 不可コマンド | 空クエリはモード不一致除外・モード一致の不可は残す。非空は一致した不可も残す。いずれも disabled＋理由 | 操作の存在を検索で学べる |
| 一覧の a11y パターン | listbox + aria-activedescendant のみ（roving なし） | 既存検索候補に近く、トラップと相性が良い |
| アウトライン行からの直接ショートカット追加 | 今 Phase では増やさない（ツールバー＋パレット）。Tab ツールバー到達は退行禁止 | キャンバス用ショートカットとの衝突と L-061 の入口増を避ける |
| コマンド履歴 | 持たない（起動のたびに空クエリの推奨セット） | YAGNI。永続化と世代管理が増える |
| 外部ライブラリ | 使わない | 既存ダイアログパターンで足りる |
| キャンバス ARIA | tree なし。`aria-label="マップキャンバス"` を付与 | ROADMAP 候補021の「キャンバスを使わず」に合致 |
| 通知の役割分担 | 成功は MapOperationNotice 等（閉じ後も残る）。パレット内 live は開いたままの拒否用 | 閉じると消える経路で成功を読ませない |
| closeReason | dismiss / execute-immediate / execute-dialog / stale | 即時成功と dismiss 復帰列を分離し、連鎖フォーカスの衝突を防ぐ |
| 第1版必須境界 | ヘッダー／アウトラインツールバー同等＋確認ダイアログ系 open。入出力・ライブラリ・閲覧ナビは第1版カタログ外（後続） | 1 プランに収める |
