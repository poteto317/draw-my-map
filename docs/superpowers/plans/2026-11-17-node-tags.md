> **状態:** 作成済み（サブエージェントレビュー前）。
>
> **For agentic workers:** このリポジトリでは AGENTS.md の規定により、サブエージェント駆動（`superpowers:subagent-driven-development`）で進める。インライン実行は使わない。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ノードに自由入力のタグを最大 10 件（各 30 文字）付けられるようにし、右パネル「ノードの詳細」の「タグ」節（メモ → タグ → リンク → イラスト）で追加・削除できるようにする。タグは保存・JSON・Undo / Redo・複製・コピー＆貼り付け・別マップへの枝の移動・分割・統合と整合し、表記違い（大文字小文字・全角半角）は同じタグとみなして重複を防ぐ。あわせて、ノードの任意の属性の扱いの表（`nodeAttributePolicy.ts`）と、全属性の往復・比較の検査を足して、属性の追加漏れを防ぐ。

**Architecture:** タグ名の規則（正規化・同一性の鍵・追加・削除・文言）は純関数（`domain/nodes/nodeTag.ts`）に集め、保存形式の検証（`mapDocumentNodeTags.ts`）・書き出し（`mapDocumentNodeProjection.ts`）・競合の比較（`mapConflict.ts`）・統合（`nodeMerge.ts` ほか）がそれを使う。履歴の比較（`mapHistory.areNodesEqual`）は候補012 で配列対応済みなので変えない。更新経路は `useNodes.addNodeTag` / `removeNodeTag`（`applyNonStructuralChange` で 1 回の履歴）だけで、表示とフォームの状態は `NodeTagsSection` が持ち、`NodeDetailPanel` が「メモ → タグ → リンク → イラスト」の順に置き、`MapEditor` が配線する。検索・キャンバス・入力候補・絞り込みは変えない。

**Tech Stack:** Next.js（App Router、React Compiler 有効）、React 19、TypeScript、Jest（jsdom、`next/jest`）、Testing Library。

**設計書:** `docs/superpowers/specs/2026-11-17-node-tags-design.md`（以下「設計書」）

**先例:** URLの添付（候補012）のプラン `docs/superpowers/plans/2026-11-17-node-links.md` と実装（`nodeLink.ts`・`mapDocumentNodeLinks.ts`・`useNodes.addNodeLink`・`NodeLinksSection.tsx`・`pageNodeLinks.test.tsx`）。多くの箇所で、`links` の直後に `tags` を同じ形で足す。

```typescript
import type { Node } from "@/types/node";

// 1 ノードに付けられるタグの件数の上限
export const NODE_TAGS_MAX_COUNT = 10;
// タグ名の長さの上限（string.length。空白をまとめた後の値に掛ける）
export const NODE_TAG_MAX_LENGTH = 30;
// 入力の長さの先行判定（前後の空白を削った後の length）。巨大な入力で空白のまとめなどの処理をしない（L-443）
export const NODE_TAG_INPUT_MAX_LENGTH = 256;

export type NodeTagNameFailureReason = "empty" | "too-long" | "invalid";

export type NodeTagNameResult =
  | { ok: true; name: string }
  | { ok: false; reason: NodeTagNameFailureReason };

export type AddNodeTagFailureReason = NodeTagNameFailureReason | "node-missing" | "duplicate" | "too-many";

export type AddNodeTagResult =
  | { ok: true; nodes: Node[] }
  | { ok: false; reason: AddNodeTagFailureReason };

// useNodes.addNodeTag の戻り値（ノード配列を含めない。AddNodeLinkOutcome と同じ分け方）
export type AddNodeTagOutcome =
  | { ok: true }
  | { ok: false; reason: AddNodeTagFailureReason };

// 連続する空白（タブ・改行・全角の空白 U+3000・NBSP・BOM を含む \s）
const WHITESPACE_RUN = /\s+/g;

// タグ名に使えない文字か（UTF-16 のコード単位で判定する。どれも BMP の文字）。
// 制御文字 U+0000〜U+0008・U+000E〜U+001F・U+007F〜U+009F（U+0085 を含む。タブ・改行などの U+0009〜U+000D は
// 先に空白としてまとめるので残らない）、ゼロ幅スペース U+200B、双方向制御 U+061C・U+200E・U+200F・U+202A〜U+202E・
// U+2066〜U+2069（見た目が同じタグが並ぶ・一覧の並びが崩れるのを避ける。L-816・L-112）。
// 絵文字の連結に使うゼロ幅結合子 U+200D は受け付ける（書式文字を一律には拒否しない）
function isForbiddenCodeUnit(code: number): boolean {
  return code <= 0x08
    || (code >= 0x0e && code <= 0x1f)
    || (code >= 0x7f && code <= 0x9f)
    || code === 0x200b
    || code === 0x061c
    || code === 0x200e
    || code === 0x200f
    || (code >= 0x202a && code <= 0x202e)
    || (code >= 0x2066 && code <= 0x2069);
}

function hasForbiddenCharacter(value: string): boolean {
  for (let index = 0; index < value.length; index += 1) {
    if (isForbiddenCodeUnit(value.charCodeAt(index))) return true;
  }
  return false;
}

// タグ名の入力を、保存する名前にする。検証と保存と表示は同じ値を使う（L-018）。
// 検査の順: 前後の空白を削る → 空 → 入力の長さの先行判定（L-443）→ 連続する空白を半角スペース 1 個にまとめる →
// 使えない文字（invalid）→ まとめた後の長さ（too-long）。大文字小文字・全角半角は変えない（最初の表記を残す）
export function normalizeNodeTagName(input: string): NodeTagNameResult {
  const trimmed = input.trim();
  if (trimmed === "") return { ok: false, reason: "empty" };
  if (trimmed.length > NODE_TAG_INPUT_MAX_LENGTH) return { ok: false, reason: "too-long" };
  const collapsed = trimmed.replace(WHITESPACE_RUN, " ");
  if (hasForbiddenCharacter(collapsed)) return { ok: false, reason: "invalid" };
  if (collapsed.length > NODE_TAG_MAX_LENGTH) return { ok: false, reason: "too-long" };
  return { ok: true, name: collapsed };
}

// 同じタグとみなすための鍵（NFKC＋小文字化）。ノード検索（domain/search/nodeLabelSearch.ts の
// normalizeNodeSearchText）と同じ規則だが、domain/search が domain/nodes に依存しているため、ここに同じ規則を持つ
export function nodeTagKey(name: string): string {
  return name.normalize("NFKC").toLowerCase();
}

// 2 つのタグの並びが同じか（要素ごと。順も区別する）。undefined は空の並びと同じに扱う
export function areNodeTagsEqual(a: readonly string[] | undefined, b: readonly string[] | undefined): boolean {
  const left = a ?? [];
  const right = b ?? [];
  return left.length === right.length && left.every((tag, index) => tag === right[index]);
}

// 利用者向けの失敗の文言。empty は部品が文言を出さないので取らない
export function formatNodeTagFailure(reason: Exclude<AddNodeTagFailureReason, "empty">): string {
  switch (reason) {
    case "too-long":
      return `タグ名が長すぎます（${NODE_TAG_MAX_LENGTH} 文字まで）。`;
    case "invalid":
      return "タグ名に使えない文字が含まれています。";
    case "duplicate":
      return "同じタグがすでに追加されています。";
    case "too-many":
      return `タグは 1 つのノードに ${NODE_TAGS_MAX_COUNT} 件まで追加できます。`;
    case "node-missing":
      return "ノードが見つかりません。";
    default: {
      const unreachable: never = reason;
      return unreachable;
    }
  }
}

// ノードのタグを tags にしたノードを返す（元のノードは変えない）。undefined・空の並びなら tags のキーごと外す
// （空配列や tags: undefined を残さない）。値の検証はしない（呼び出し側の責務）
export function withNodeTags(node: Node, tags: readonly string[] | undefined): Node {
  if (tags !== undefined && tags.length > 0) return { ...node, tags };
  // eslint-disable-next-line @typescript-eslint/no-unused-vars -- 分割代入で tags を除外するため
  const { tags: _removed, ...rest } = node;
  return rest;
}

// 1 ノードのタグの末尾に 1 件足す。検査の順: node-missing → タグ名の検査 → duplicate（nodeTagKey が同じ）→ too-many。
// 成功時は対象のノードだけを新しいオブジェクトにし、ほかのノードは同じ参照のまま返す
export function addNodeTag(nodes: readonly Node[], id: number, input: string): AddNodeTagResult {
  const target = nodes.find((node) => node.id === id);
  if (target === undefined) return { ok: false, reason: "node-missing" };
  const normalized = normalizeNodeTagName(input);
  if (!normalized.ok) return normalized;
  const current = target.tags ?? [];
  const key = nodeTagKey(normalized.name);
  if (current.some((tag) => nodeTagKey(tag) === key)) return { ok: false, reason: "duplicate" };
  if (current.length >= NODE_TAGS_MAX_COUNT) return { ok: false, reason: "too-many" };
  const nextTags = [...current, normalized.name];
  return { ok: true, nodes: nodes.map((node) => (node.id === id ? withNodeTags(node, nextTags) : node)) };
}

// 1 ノードからタグを 1 件消す。tag は保存されている名前と完全に一致するものだけを消す（表記違いは消さない）。
// 対象が無い・そのタグを持たないときは null（何も変えない）。最後の 1 件を消すと tags のキーごと外す
export function removeNodeTag(nodes: readonly Node[], id: number, tag: string): Node[] | null {
  const target = nodes.find((node) => node.id === id);
  const tags = target?.tags;
  if (tags === undefined || !tags.includes(tag)) return null;
  const nextTags = tags.filter((item) => item !== tag);
  return nodes.map((node) => (node.id === id ? withNodeTags(node, nextTags) : node));
}
```

```typescript
import {
  NODE_TAGS_MAX_COUNT,
  NODE_TAG_INPUT_MAX_LENGTH,
  NODE_TAG_MAX_LENGTH,
  nodeTagKey,
  normalizeNodeTagName,
} from "@/domain/nodes/nodeTag";
import type { MapDocumentResult, MapDocumentVersion } from "@/types/mapDocument";

function failure(index: number): MapDocumentResult<readonly string[] | undefined> {
  return {
    ok: false,
    error: `node[${index}].tagsは、${NODE_TAG_MAX_LENGTH}文字以内のタグ名の配列（最大${NODE_TAGS_MAX_COUNT}件）である必要があります。`,
  };
}

// 件数と各要素の型・長さ（前後の空白を削る前の length）を、タグ名の正規化より先に判定する（L-443）
function isBoundedStringArray(values: readonly unknown[]): values is readonly string[] {
  return values.length <= NODE_TAGS_MAX_COUNT
    && values.every((value) => typeof value === "string" && value.length <= NODE_TAG_INPUT_MAX_LENGTH);
}

// タグは version 3 の任意項目。それ以前の version では、あっても無視する。
// 各要素は normalizeNodeTagName で正規化した名前にし、nodeTagKey が同じものは後のものを捨て、空になれば undefined
export function normalizeMapDocumentNodeTags(
  tags: unknown,
  index: number,
  version: MapDocumentVersion,
): MapDocumentResult<readonly string[] | undefined> {
  if (version !== 3 || tags === undefined) {
    return { ok: true, value: undefined };
  }
  if (!Array.isArray(tags) || !isBoundedStringArray(tags)) {
    return failure(index);
  }
  const normalized: string[] = [];
  const keys = new Set<string>();
  for (const tag of tags) {
    const result = normalizeNodeTagName(tag);
    if (!result.ok) return failure(index);
    const key = nodeTagKey(result.name);
    if (keys.has(key)) continue;
    keys.add(key);
    normalized.push(result.name);
  }
  return { ok: true, value: normalized.length === 0 ? undefined : normalized };
}
```

```typescript
function uniqueNodeTags(tags: readonly string[]): string[] {

  const unique: string[] = [];
```

```tsx
    createTestNode({ id: 1, label: "りんご", ...(tags === undefined ? {} : { tags }) }),
  ]);
  const addTag = (id: number, input: string): AddNodeTagOutcome => {
    onAdd(id, input);
    const result = addNodeTag(nodes, id, input);
    if (!result.ok) return { ok: false, reason: result.reason };
    setNodes(result.nodes);
    return { ok: true };
  };
  const removeTag = (id: number, tag: string): boolean => {
    onRemove(id, tag);
    const next = removeNodeTag(nodes, id, tag);
    if (next === null) return false;
    setNodes(next);
    return true;
  };
  return (
    <NodeTagsSection
      node={nodes[0]}
      documentRevision={documentRevision}
      onAddTag={addTag}
      onRemoveTag={removeTag}
    />
  );
}
```

```tsx
"use client";

import { useId, useRef, useState, type FormEvent, type KeyboardEvent } from "react";
import { getNodeDisplayLabel } from "@/domain/nodes/nodeDisplayLabel";
import { NODE_TAGS_MAX_COUNT, formatNodeTagFailure, type AddNodeTagOutcome } from "@/domain/nodes/nodeTag";
import type { Node } from "@/types/node";

type NodeTagsSectionProps = {
  // 対象のノード（主選択）。未選択のときは null
  node: Pick<Node, "id" | "label" | "tags"> | null;
  // 文書の世代（useNodes の documentRevision）。変わったら入力欄の下書きとエラーを消す
  documentRevision: number;
  onAddTag: (id: number, input: string) => AddNodeTagOutcome;
  onRemoveTag: (id: number, tag: string) => boolean;
};

const NO_TAGS: readonly string[] = [];

const buttonClassName = "shrink-0 rounded-md bg-zinc-100 px-2 py-1 text-xs text-zinc-700 transition-colors hover:bg-zinc-200 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600 dark:bg-zinc-700 dark:text-zinc-200 dark:hover:bg-zinc-600";

// 右パネルの「タグ」節。一覧（削除）と追加のフォームを持ち、入力欄の下書き・エラーの文言・フォーカスを受け持つ。
// NodeDetailPanel が対象のノードの ID だけを key にして作り直す（別のノードの下書きを引き継がない）。
// documentRevision（Undo / Redo・JSON 読み込み・マップの切り替えで増える）では作り直さず、描画中に前回の世代と比べて
// 下書きとエラーだけを消す（L-588）。作り直すと、削除ボタンにあったフォーカスが body へ落ち、続けて押した
// Delete などのキーがマップの操作になるため（L-155）。入力欄とボタンは disabled にしない（L-155・L-157）
export function NodeTagsSection({ node, documentRevision, onAddTag, onRemoveTag }: NodeTagsSectionProps) {
  const headingId = useId();
  const inputId = useId();
  const countId = useId();
  const errorId = useId();
  const inputRef = useRef<HTMLInputElement>(null);
  const [input, setInput] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [seenRevision, setSeenRevision] = useState(documentRevision);

  // 文書が入れ替わったら、古い下書きとエラーを新しい文書へ残さない（レンダー中に調整し、effect 内の同期 setState を避ける）
  if (documentRevision !== seenRevision) {
    setSeenRevision(documentRevision);
    setInput("");
    setError(null);
  }
  const tags = node?.tags ?? NO_TAGS;
  const isAtLimit = tags.length >= NODE_TAGS_MAX_COUNT;

  // 確定は送信の 1 か所だけ（noValidate でブラウザの検証を止め、独自の文言を出す。L-057・L-161）
  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    if (node === null || input.trim() === "") return;
    const outcome = onAddTag(node.id, input);
    if (outcome.ok) {
      setInput("");
      setError(null);
      inputRef.current?.focus();
      return;
    }
    if (outcome.reason !== "empty") setError(formatNodeTagFailure(outcome.reason));
  };

  // IME の変換中の Enter（L-474）と、押し続けの Enter（L-408）では送信しない
  const handleKeyDown = (event: KeyboardEvent<HTMLInputElement>) => {
    if (event.key !== "Enter") return;
    if (event.nativeEvent.isComposing || event.keyCode === 229 || event.repeat) event.preventDefault();
  };

  // 押した削除ボタンは消えるので、フォーカスを常に有効な入力欄へ移す（L-155）
  const handleRemove = (tag: string) => {
    if (node === null) return;
    if (onRemoveTag(node.id, tag)) setError(null);
    inputRef.current?.focus();
  };

  return (
    <section aria-labelledby={headingId} className="flex flex-col gap-2">
      <h2 id={headingId} className="text-sm font-semibold text-zinc-800 dark:text-zinc-100">タグ</h2>
      {node === null ? (
        <p className="text-sm text-zinc-500 dark:text-zinc-400">ノードを選択してください</p>
      ) : (
        <>
          <div className="flex flex-col gap-1">
            <span className="text-xs text-zinc-500 dark:text-zinc-400">対象ノード</span>
            <p
              className="line-clamp-3 break-words text-sm text-zinc-800 dark:text-zinc-100"
              title={node.label || undefined}
            >
              {getNodeDisplayLabel(node.label)}
            </p>
          </div>
          {tags.length === 0 ? (
            <p className="text-sm text-zinc-500 dark:text-zinc-400">タグはありません</p>
          ) : (
            <ul className="flex flex-wrap gap-1">
              {tags.map((tag) => (
                <li
                  key={tag}
                  className="flex max-w-full items-center gap-1 rounded-md bg-zinc-100 py-0.5 pl-2 pr-0.5 dark:bg-zinc-700"
                >
                  <span className="min-w-0 break-words text-sm text-zinc-800 dark:text-zinc-100" title={tag}>{tag}</span>
                  <button
                    type="button"
                    aria-label={`タグを削除: ${tag}`}
                    className="shrink-0 rounded px-1 text-xs text-zinc-600 hover:bg-zinc-200 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600 dark:text-zinc-300 dark:hover:bg-zinc-600"
                    onClick={() => handleRemove(tag)}
                  >
                    <span aria-hidden="true">×</span>
                  </button>
                </li>
              ))}
            </ul>
          )}
          <div className="flex flex-wrap items-baseline gap-x-2">
            <p id={countId} className="text-xs text-zinc-500 dark:text-zinc-400">
              {`${tags.length} / ${NODE_TAGS_MAX_COUNT} 件`}
            </p>
```

```markdown
## 26. タグ

Phase 18・候補023。親子関係とは別の分類軸（「重要」「資料あり」「Python」など）を、ノードに付けられるようにします。タグはノードごとの文字列（自由入力）で、マップ全体のタグ一覧は持ちません（名前の変更・色の管理はしません）。

### 26.1 操作と表示

| 項目 | 内容 |
| :--- | :--- |

### 26.2 タグ名の規則と、同じタグとみなす規則

- 前後の空白を削ります。空（空白だけ）のときは何もしません。
- 連続する空白（タブ・改行・全角の空白を含む）は、半角スペース 1 個にまとめます（例: `機械　　学習` → `機械 学習`）。
- 制御文字、ゼロ幅スペース（`U+200B`）、双方向制御の文字（`U+061C`・`U+200E`・`U+200F`・`U+202A`〜`U+202E`・`U+2066`〜`U+2069`）を含む名前は受け付けません（見た目が同じタグが並ぶ・一覧の並びが崩れるのを避けるため）。絵文字の連結に使うゼロ幅結合子（`U+200D`）は受け付けます。
- 長さは空白をまとめた後で **30 文字**まで（`string.length`。絵文字などは 1 文字で 2 と数えるものがあり、絵文字 15 個で 30 文字）。前後の空白を削った入力が 256 文字を超えるときは、ほかの処理より先に「長すぎる」とします。
- 1 ノードに **10 件**まで。
- **大文字小文字・全角半角は区別しません**（ノード検索と同じ規則（NFKC＋小文字化）で比べます。例: `Python`・`python`・`Ｐｙｔｈｏｎ` は同じタグ）。同じノードに同じタグは付けられません。表示と保存は**最初に入力した表記**のままです。
- `#` で始まる名前も、そのまま名前として扱います（特別な意味はありません）。

### 26.3 追加・削除と履歴

| 操作 | 挙動 |
| :--- | :--- |
| 追加に成功 | 一覧の末尾に足し、入力欄を空にしてフォーカスを入力欄に残します。**1 回の履歴**になります |
| 追加に失敗 | 入力を残し、入力欄の下に理由を `role="alert"` で出します（26.4 節）。入力を変えると消えます。履歴は積みません |
| 空のまま追加 | 何もしません（理由も出しません） |

| 削除 | そのタグだけを消し、**1 回の履歴**になります。押したボタンは消えるので、フォーカスを入力欄へ移します。最後の 1 件を消すと、ノードは `tags` の項目を持たなくなります |
```
