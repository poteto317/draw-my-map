# Phase 1: ノードの基本操作 — バックログ

Phase 1 のゴール：マインドマップのノードを「作成 → テキスト入力 → 移動 → 削除」する一連の基本操作を完成させる。

---

## 1-1. データモデルのリネームと拡張

現在の `Rect` 型をマインドマップのノードとして扱えるように拡張する。

### タスク

- [x] `Rect` 型を `Node` 型にリネームする（`types/rect.ts` → `types/node.ts`）
- [x] `Node` 型に `label: string`（テキスト）フィールドを追加する
- [x] `useRects` フックを `useNodes` にリネームする（`hooks/useRects.ts` → `hooks/useNodes.ts`）
- [x] `addRect` を `addNode` にリネームし、初期テキスト（空文字）を設定するようにする
- [x] 既存テスト（`useRects.test.ts`）をリネーム・修正する
- [x] `MapStage` の props と内部ロジックを新しい命名に合わせて更新する
- [x] `page.tsx` のインポートと呼び出しを更新する

### 完了条件

- [x] 既存の動作（ダブルクリックでノード追加）が変わらず動く
- [x] `npm run verify` が通る

- [x] 新規ノード追加時にデフォルトテキスト（例:「新しいノード」）を設定する

### 完了条件

- [x] ノードをダブルクリックするとテキスト編集できる
- [x] Enter / blur で確定、Escape でキャンセルされる
- [ ] テキストに応じてノードサイズが調整される ※後続タスクで対応

選択中のノードをキーボード操作で削除する。

- [x] 選択中のノードがある場合のみ削除を実行する

- [x] 削除後に選択状態をクリアする
- [x] テスト: 削除ロジックを確認する

- [x] ノード選択中に Delete / Backspace を押すとノードが消える

## 実装順序

依存関係を考慮した推奨順序:

```
1-1 データモデルのリネームと拡張
 ↓
1-2 テキスト表示
 ↓
1-3 クリック選択  ←  他の機能の前提
 ↓              ↓
1-5 ドラッグ移動  1-4 テキスト編集
                 ↓
                1-6 削除
```
